Write a Python module `sudoku.py` for reading, checking and solving standard 9×9 sudoku puzzles.

A *grid* is a list of 9 rows, each a list of 9 `int`s from 0 to 9, where 0 is an empty cell. Every function that takes a grid raises `ValueError` if it does not have that shape and those values.

- `parse(text: str) -> list[list[int]]`: reads 81 cells in row-major order. Digits `1`–`9` are givens; `0` and `.` are empty cells; whitespace (spaces, tabs, newlines) is ignored anywhere. Any other character, or a cell count other than 81, raises `ValueError`.
- `to_string(grid) -> str`: the 81 cells as one line in row-major order, with `.` for empty cells and no whitespace.
- `is_valid(grid) -> bool`: `True` if no digit 1–9 appears twice in any row, column or 3×3 box. Empty cells never conflict, and the grid need not be complete.
- `solve(grid) -> list[list[int]] | None`: a completed, valid grid that keeps every given of `grid`, or `None` if there is none (including when `grid` is not valid). If several solutions exist, any one of them may be returned. The argument is never modified; the result is a new grid.
- `count_solutions(grid, limit: int = 2) -> int`: the number of solutions, counting stops as soon as `limit` is reached, so the result is `min(number of solutions, limit)`. An invalid grid has 0 solutions. `ValueError` if `limit < 1`. The argument is never modified.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
