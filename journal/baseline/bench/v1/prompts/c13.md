Write a Python module `ratelimit.py` with a token-bucket rate limiter, `class TokenBucket`.

- `TokenBucket(rate, capacity, clock=time.monotonic)`: `rate` is the number of tokens added per second and `capacity` the most tokens the bucket can hold. Both are numbers (int or float) greater than 0, otherwise `ValueError`. `clock` is a function with no arguments that returns the current time in seconds; the bucket reads the time only by calling it. The bucket starts full, at the time `clock()` returns during construction.
- Refill: every method first brings the bucket up to date. Tokens accrue continuously at `rate` per second of clock time since the previous reading, and the count never exceeds `capacity` (time spent full is lost). Counts are fractional: half a second at rate 1 adds 0.5 tokens. If the clock returns a time earlier than the latest time it has returned so far, no time has passed, nothing is added or removed, and the later time stays the reference for the next refill.
- `try_acquire(n=1) -> bool`: if at least `n` tokens are available, remove `n` and return `True`; otherwise return `False` and remove nothing.
- `wait_time(n=1) -> float`: the number of seconds from now until `try_acquire(n)` would succeed if nothing else took tokens in the meantime: `0.0` if it would succeed now. It removes nothing.
- `available() -> float`: the current number of tokens.
- For `try_acquire` and `wait_time`, `n` must be greater than 0 and at most `capacity`, otherwise `ValueError` (a request larger than the bucket could never succeed).

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
