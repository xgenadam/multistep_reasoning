Write a command-line tool `csv2json.py` that converts a CSV file to a JSON array of objects.

Usage: `python csv2json.py PATH [--indent N]`.

Input:
- PATH is read as UTF-8; a leading byte-order mark, if present, is not part of the data.
- The CSV dialect is the usual one: fields separated by commas, records separated by `\n` or `\r\n`, and a field may be wrapped in double quotes, in which case it can contain commas, line breaks and doubled double quotes (`""` stands for one `"`). Line breaks inside a quoted field are kept exactly as they are in the file.
- Records that are completely empty (a blank line) are skipped wherever they appear.
- The first non-skipped record is the header. Each later record becomes one JSON object whose keys are the header fields, in header order, and whose values are the record's fields as strings, never converted to numbers or anything else.
- A record with fewer fields than the header gets `null` for each missing field.
- A record with more fields than the header is an error: print `csv2json.py: record R has F fields, expected H` to standard error and exit with status 1, printing nothing on standard output. R counts records from 1 for the header, skipped blank records not counted; F and H are the two field counts.

Output:
- Without `--indent`, print the array on one line in the form `json.dumps(records, ensure_ascii=False)` produces, then a newline.
- With `--indent N`, where N is an integer of 0 or more, print it as `json.dumps(records, indent=N, ensure_ascii=False)` produces, then a newline. A value of N that is not such an integer is a usage error: a message containing `usage` on standard error and exit status 2.
- A file with a header and no data records prints `[]`.
- On success the exit status is 0 and nothing is written to standard error.

Other errors, each with exit status 2 and nothing on standard output:
- PATH does not exist or is not a regular file: `csv2json.py: no such file: PATH` on standard error.
- PATH has no header, because it is empty or contains only blank lines: `csv2json.py: empty file: PATH` on standard error.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
