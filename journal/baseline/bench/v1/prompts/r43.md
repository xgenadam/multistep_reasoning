I am putting together the reading pack for a "history of computing" evening course for working software developers. I need a long essay on how programming languages developed from the 1950s to the 2010s: what each language was for, what new ideas it introduced, and how ideas passed from one language to the next. Please write it, about 6,500 words.

The readers are professional developers who know two or three modern languages well and little about where their ideas came from. Write in an engaging, well-informed style. Be accurate, explain ideas with short concrete examples where useful (a line or two of code is fine), and avoid trivia for its own sake. Treat each language's year as the year given below (its first public appearance), and do not use other dates for these languages.

**Structure.** Use these headings, in this order:
1. Introduction
2. The 1950s
3. The 1960s
4. The 1970s
5. The 1980s
6. The 1990s
7. The 2000s
8. The 2010s
9. Timeline
10. Conclusion

You may add a subtitle after each decade heading (for example "The 1970s: Systems and Structure").

**The languages for each decade.** Cover exactly these languages in their decade's section, and no others as main entries (you may mention other languages in passing):
- 1950s: FORTRAN (1957), LISP (1958), ALGOL 58 (1958), COBOL (1959)
- 1960s: ALGOL 60 (1960), BASIC (1964), PL/I (1964), Simula (1967), Logo (1967)
- 1970s: Pascal (1970), C (1972), Smalltalk (1972), Prolog (1972), ML (1973), Scheme (1975)
- 1980s: Ada (1980), Objective-C (1984), C++ (1985), Erlang (1986), Perl (1987)
- 1990s: Haskell (1990), Python (1991), Java (1995), JavaScript (1995), Ruby (1995), PHP (1995)
- 2000s: C# (2000), Scala (2004), F# (2005), Clojure (2007), Go (2009)
- 2010s: Rust (2010), Kotlin (2011), Julia (2012), TypeScript (2012), Swift (2014)

**Each decade section** opens with a paragraph on the computing context of the time (the machines, who programmed them and why), then covers each of its languages, and ends with a subsection headed "Influences" that traces which earlier ideas the decade's languages borrowed and which later languages they shaped.

**Timeline.** A single table with exactly one row for each of the 36 languages above and no other rows, sorted by year (and alphabetically within a year), with the columns Year, Language, Key idea introduced or popularised, Main influence on later languages, in that order.

**Conclusion.** Draw out three or four recurring patterns across the seventy years, without repeating the decade sections' content.

Do not cover languages that first appeared after 2019.
