Extend `calc.py` with powers, variables and functions. Everything from the previous version keeps working exactly as before, including every error position.

- The signature becomes `evaluate(expr: str, variables=None) -> Fraction`. `variables` is a mapping from names to values that are `int` or `Fraction`, or `None` for no variables.
- A name is a letter or `_` followed by letters, digits or `_`. A name followed by `(` (spaces and tabs may come between them) is a function call; any other name is a variable, and evaluates to its value in `variables`.
- Functions: `abs(x)` takes exactly one argument; `min(x, ...)` and `max(x, ...)` take one or more. Arguments are full expressions separated by commas. Commas are allowed nowhere else.
- `**` is exponentiation. The two characters must be adjacent: `2 * * 3` is a syntax error at the second `*`. It binds tighter than every other operator, including a unary minus on its left, it groups from the right, and its right operand may start with unary minus. So `-2 ** 2` is `-4`, `2 ** -1` is `1/2`, `2 ** 3 ** 2` is `512` and `(1/2) ** 2` is `1/4`.

Errors are still `CalcError` with a 0-based `position`.
- Syntax errors follow the same rule as before. For example `min(1,)` → 6, `max(` → 4, `abs(1 2)` → 6, `1, 2` → 1.
- These are evaluation errors, like division by zero. They are reported only when the expression has no syntax error, and if there are several the first one met when evaluating left to right is reported. A function's name and argument count are checked before its arguments are evaluated.
  - An unknown variable, or any variable when `variables` is `None`: the position of the name.
  - An unknown function, or a wrong number of arguments (`min()`, `abs(1, 2)`): the position of the function name.
  - An exponent that is not a whole number (`4 ** 0.5`): the position of the `**`.
  - `0` raised to a negative power is a division by zero: the position of the `**`.

Use only the Python 3.12 standard library. Give the complete updated files, each in its own fenced code block, with the file's path on the line just before the block.
