Write a small spreadsheet engine as a Python package `sheet`. Cells hold numbers, text or formulas; the sheet keeps track of which cells depend on which and recalculates only what a change affects. The package has four files:

- `sheet/__init__.py` re-exports `Sheet`, `DependencyGraph`, `FormulaError`, `ErrorValue`, `parse_formula`, `references` and `evaluate`.
- `sheet/formula.py`: formula parsing and evaluation, `FormulaError` and `ErrorValue`.
- `sheet/graph.py`: `DependencyGraph`.
- `sheet/sheet.py`: `Sheet`.

## Cells and values

- The sheet has columns `A` to `Z` and rows `1` to `999`. A cell name is one column letter followed by the row number written without leading zeros, for example `B7` or `Z999`. Names are case-insensitive (`b7` is `B7`); every name the package returns is in upper case.
- *Row-major order* sorts cell names by row number, then by column letter: `B1, A2, C2, A10`.
- A cell's value is an `int`, a `float`, a `str` (text), `None` (an empty cell), or an error value.
- Error values are instances of `ErrorValue`, a subclass of `str` defined in `sheet/formula.py`, so they compare equal to their text. There are two: `#ERROR!` (any failed calculation) and `#CYCLE!` (a circular reference).

## Formulas (`sheet/formula.py`)

A formula is the text after the leading `=`. Its grammar, with whitespace allowed anywhere between tokens:

```
expr   := term {(+ | -) term}
term   := unary {(* | /) unary}
unary  := (+ | -) unary | number | ref | ( expr )
number := digits [. digits]            (no sign, no exponent)
ref    := letters digits               (case-insensitive)
```

`*` and `/` bind tighter than `+` and `-`, and all four are left-associative; a unary sign binds tighter than any binary operator, so `-2*3` is `(-2)*3`.

- `class FormulaError(ValueError)`.
- `parse_formula(source: str)` parses the text after `=` and returns a syntax tree (its classes are up to you). It raises `FormulaError` for empty input, any character outside the grammar, an incomplete expression, unbalanced parentheses, or a reference outside the sheet (more than one letter, a row of 0 or above 999, or a row with a leading zero, such as `AA1`, `A0`, `B1000`, `A01`).
- `references(tree) -> set[str]` returns the upper-case names of the cells the formula refers to.
- `evaluate(tree, lookup)` computes the formula's value. `lookup(name)` takes an upper-case name and returns that cell's current value. The rules:
  1. A number literal is an `int` when it has no `.`, else a `float`.
  2. A reference gives the cell's value, except that an empty cell (`None`) gives `0`. A formula that is only a reference therefore returns text unchanged (`=A1` where `A1` holds `hi` gives `'hi'`).
  3. The operators (`+ - * /` and the unary signs) evaluate their operands left to right. If an operand is an error value, the result is that error value (the left one if both are). Otherwise, if an operand is text, the result is `#ERROR!`.
  4. `+`, `-` and `*` on two `int`s give an `int`; with a `float` they give a `float`. `/` always gives a `float`, and dividing by zero gives `#ERROR!`.

## `sheet/graph.py`

`DependencyGraph()` records, for each cell, the cells its formula refers to (its *precedents*). All names it receives are already upper case.

- `set_dependencies(cell: str, precedents)` replaces `cell`'s precedents with the given iterable of names (empty removes them).
- `precedents(cell) -> set[str]` and `dependents(cell) -> set[str]` give the direct links in each direction (an empty set for an unknown cell).
- `all_dependents(cell) -> set[str]` gives every cell that refers to `cell` directly or through other cells. It contains `cell` itself only when `cell` is on a cycle.
- `cycle_cells() -> set[str]` gives every cell that lies on a cycle, that is, a cell from which following precedents leads back to itself (a cell that refers to itself is on a cycle).

## `sheet/sheet.py`

`Sheet()` creates an empty sheet with these methods. Every method that takes a name raises `ValueError` for a name outside the sheet.

- `set(name: str, raw: str) -> list[str]` stores the cell's input. `raw` must be a `str` (`TypeError` otherwise).
  - `''` empties the cell.
  - Text that starts with `=` is a formula. If `parse_formula` raises `FormulaError`, `set` re-raises it and the sheet is left completely unchanged.
  - Otherwise, if `raw` with surrounding whitespace removed is an optional `-` followed by `digits [. digits]`, the value is that number (an `int` without `.`, else a `float`).
  - Anything else is text, stored exactly as given (spaces included).
  - It returns the cells whose value may have changed, in row-major order: the cell itself plus every cell in its `all_dependents`.
- `get(name: str)` returns the cell's value (`None` for an empty cell).
- `raw(name: str) -> str` returns the input last stored (`''` for an empty cell).
- `cells() -> list[str]` returns the non-empty cells in row-major order.
- `evaluations` is an `int` attribute: how many times a formula has been evaluated since the sheet was created.

Recalculation rules:

1. After every `set`, every cell's value is as if the whole sheet had been calculated from scratch.
2. A cell on a cycle has the value `#CYCLE!` and is not evaluated. A cell that refers to a `#CYCLE!` cell gets `#CYCLE!` through rule 3 of evaluation.
3. `set` evaluates each formula cell in its returned list that is not on a cycle exactly once, after all of the cells it refers to are up to date, and evaluates no other cell. So `evaluations` grows by exactly that number.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
