Write a Python module `trie.py` with a class `Autocomplete` that suggests stored words for a typed prefix, using a trie.

- Matching is case-insensitive: words and prefixes are compared by their `str.casefold()` form, but suggestions are returned in the spelling the word was added with.
- `add(word: str, weight: float = 1)` stores a word with a weight (a number; larger means more relevant). `ValueError` if `word` is empty. If a word with the same casefolded form is already stored, it is replaced: both the stored spelling and the weight become the new ones.
- `complete(prefix: str, k: int = 10) -> list[str]` returns up to `k` stored words whose casefolded form starts with the casefolded `prefix`, ordered by weight from highest to lowest, and among equal weights alphabetically by casefolded form. The empty prefix matches every word. `k = 0` returns `[]`; a negative `k` raises `ValueError`.
- `delete(word: str) -> bool` removes the stored word with the same casefolded form and returns `True`, or returns `False` if there is none.
- `len(ac)` is the number of stored words, and `word in ac` tells whether a word with that casefolded form is stored.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
