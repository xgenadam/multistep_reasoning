Write a lending system for a small public library as the package `library/`, in four files: `library/__init__.py`, `library/catalog.py`, `library/loans.py` and `library/fines.py`. Dates are `datetime.date` values. The library never reads the system clock: it is given a `clock`, a function with no arguments that returns today's date, and calls it whenever it needs "today".

## `library/fines.py`: the policy

`Policy` is a frozen dataclass with the fields `max_loans`, `loan_days`, `renewals`, `daily_fine`, `fine_cap` and `grace_days` (all `int`, money in cents). `POLICY: dict[str, Policy]` holds this table, keyed by member kind:

| kind | max_loans | loan_days | renewals | daily_fine | fine_cap | grace_days |
| --- | --- | --- | --- | --- | --- | --- |
| `standard` | 5 | 21 | 2 | 25 | 1000 | 0 |
| `student` | 3 | 14 | 1 | 10 | 500 | 2 |
| `staff` | 10 | 42 | 3 | 0 | 0 | 0 |

Also in this module:
- `HOLD_PICKUP_DAYS = 3`.
- `due_date(start: date, days: int) -> date`: `start + days`, except that a result falling on a Sunday moves to the following Monday.
- `fine_for(kind: str, due: date, returned: date) -> int`: with `late = (returned - due).days`, the fine is 0 if `late <= grace_days`; otherwise it is `min(late * daily_fine, fine_cap)`. Once past the grace period every late day counts, including the grace days. An unknown kind raises `KeyError`.

## `library/catalog.py`

- `Book`: a dataclass with `isbn: str`, `title: str`, `author: str`, `copies: int`.
- `Member`: a dataclass with `member_id: str`, `name: str`, `kind: str`.
- `Catalog()`:
  - `add_book(isbn, title, author, copies=1) -> Book`: `ValueError` if the isbn exists or `copies < 1`.
  - `add_copies(isbn, n) -> int`: adds `n ≥ 1` copies (`ValueError` otherwise) and returns the new total; `KeyError` for an unknown isbn.
  - `add_member(member_id, name, kind='standard') -> Member`: `ValueError` if the id exists or `kind` is not in `POLICY`.
  - `book(isbn)` and `member(member_id)`: look-ups that raise `KeyError` when missing.
  - `search(text) -> list[Book]`: books whose title or author contains `text`, ignoring case, sorted by title and then isbn.

## `library/loans.py`

Exceptions: `LoanError(Exception)` and its subclasses `Blocked`, `DuplicateLoan`, `LimitReached`, `NotAvailable` and `RenewalRefused`.

`Loan` is a dataclass with `loan_id: int`, `member_id: str`, `isbn: str`, `start: date`, `due: date`, `renewals: int = 0`, `returned: date | None = None` and `fine: int = 0`. Loan ids are 1, 2, 3, … in checkout order.

`Library(catalog: Catalog, clock)` has these methods. Unknown member ids, isbns and loan ids raise `KeyError`.

**Availability and holds.** For an isbn, `available(isbn) -> int` is its copies minus its active loans minus its *ready* holds. Each isbn has one hold queue in the order holds were placed. A hold is *waiting* until a copy is set aside for it, then *ready* with a pickup deadline.
- When a copy is checked in and the isbn has a waiting hold, the copy is set aside for the earliest waiting hold, which becomes ready with deadline `today + HOLD_PICKUP_DAYS`. Copies added with `add_copies` are not set aside.
- A ready hold may be picked up up to and including its deadline. On the day after the deadline the hold is removed and its copy passes to the next waiting hold, which becomes ready with deadline `that day + HOLD_PICKUP_DAYS`; if there is none, the copy becomes available. This happens as if a job ran at the start of every day: whenever the library looks at today's date, it first applies every expiry that should have happened by then, in date order, so the result never depends on which days the library was used.

Methods:
- `checkout(member_id, isbn) -> Loan`: lends a copy for `due_date(today, loan_days)` of the member's kind. Checks in this order:
  1. `Blocked` if the member's fine balance is above 0.
  2. `DuplicateLoan` if the member already has this isbn on loan.
  3. `LimitReached` if the member has `max_loans` active loans.
  4. If the member has a ready hold on the isbn, the set-aside copy is used and the hold is removed. Otherwise `NotAvailable` if `available(isbn)` is 0. A successful checkout also removes the member's waiting hold on the isbn, if any.
- `place_hold(member_id, isbn) -> int`: adds a waiting hold at the end of the queue and returns its 1-based position in the whole queue. `DuplicateLoan` if the member already has the isbn on loan or already has a hold on it; `LoanError` (the base class itself) if `available(isbn)` is above 0.
- `cancel_hold(member_id, isbn) -> None`: removes the member's hold (`KeyError` if there is none). Cancelling a ready hold passes its copy on as if it had expired today: the next waiting hold becomes ready with deadline `today + HOLD_PICKUP_DAYS`.
- `holds(isbn) -> list[str]`: the member ids in the queue, in order.
- `hold_status(member_id, isbn)`: `('ready', deadline)` or `('waiting', position)` with the 1-based position in the whole queue; `KeyError` if there is no hold.
- `renew(loan_id) -> date`: sets and returns a new due date, `due_date(old_due, loan_days)`, counted from the old due date, not from today. `LoanError` if the loan was already returned. Otherwise `RenewalRefused`, checked in this order, if the loan is overdue (today after the due date), if the isbn has any hold, waiting or ready, or if the loan has used all its renewals.
- `checkin(loan_id) -> int`: marks the loan returned today, computes its fine with `fine_for`, stores it on the loan, adds it to the member's balance, sets the copy aside for a waiting hold if there is one, and returns the fine. `LoanError` if already returned.
- `accrued_fine(loan_id) -> int`: the fine the loan would be charged if checked in today (the stored fine for a returned loan).
- `balance(member_id) -> int` and `pay(member_id, amount) -> int`: `pay` reduces the balance and returns what is left; `ValueError` if `amount <= 0` or `amount` is above the balance.
- `loans(member_id) -> list[Loan]`: the member's active loans sorted by due date and then loan id.
- `overdue() -> list[Loan]`: every active loan whose due date is before today, sorted by due date and then loan id.

`library/__init__.py` re-exports `Catalog`, `Book`, `Member`, `Library`, `Loan`, `POLICY`, `Policy`, `HOLD_PICKUP_DAYS`, `due_date`, `fine_for` and the six exceptions.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
