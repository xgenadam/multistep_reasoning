Write a command-line script `csvdedup.py` that removes duplicate rows from a CSV file.

Usage: `python csvdedup.py PATH --key COL[,COL...] [--keep first|last]`

- `PATH` is a UTF-8 CSV file read with the `csv` module (default dialect, so quoted fields may contain commas, quotes and newlines). Its first row is the header.
- `--key` (required) is a comma-separated list of header names. Two data rows are duplicates when their values in all key columns are equal as exact strings. A row with fewer fields than the header counts as having empty strings in the missing columns.
- `--keep first` (the default) keeps the first row of each group of duplicates; `--keep last` keeps the last one. Either way, the kept rows are written in the order they appear in the input, so with `--keep last` a kept row appears where its last occurrence was.
- Output on stdout: the header, then the kept rows, written with `csv.writer` (default dialect) using `lineterminator='\n'`. Rows are written exactly as read.
- On success, print `kept K of N rows` on stderr, where `N` is the number of data rows read (not counting the header) and `K` the number written, and exit 0. A file with only a header gives `kept 0 of 0 rows`.
- Errors print one message on stderr, nothing on stdout:
  - a `--key` name that is not in the header: `csvdedup: unknown column: NAME` (the first such name in `--key` order), exit 2;
  - `PATH` cannot be read: `csvdedup: cannot read PATH`, exit 1; an empty file (no header row): `csvdedup: empty file`, exit 1;
  - usage errors (no `--key`, a `--keep` value other than `first` or `last`) as `argparse` reports them, exit 2.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
