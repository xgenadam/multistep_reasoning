Extend the `sheet` package with range functions and specific error values. Everything else (cell names, constants and text, the `Sheet`, `DependencyGraph` and `references`/`evaluate` interfaces, row-major order, cycle handling, the returned lists and the `evaluations` count) works exactly as before.

## Error values

There are now four error values, all still `ErrorValue` instances, and `#ERROR!` no longer exists:

- `#DIV/0!`: division by zero, and `AVG` with no numbers to average;
- `#VALUE!`: text used where a number is needed (an operand of `+ - * /` or a unary sign, or a function argument that is not a range or a reference, see below);
- `#REF!`: a reference to a cell outside the sheet;
- `#CYCLE!`: as before.

Errors propagate as before: the operands of an operator are evaluated left to right, and if any is an error value the result is the leftmost error, ahead of any `#VALUE!` for text.

## References outside the sheet

A reference is still letters followed by digits, but one outside the sheet (`AA1`, `A0`, `B1000`, `A01`) is no longer a `FormulaError`: it parses, and evaluating it gives `#REF!`. `references` returns only cells inside the sheet. Cell names given to `Sheet` methods outside the sheet still raise `ValueError`.

## Functions and ranges

The grammar gains function calls:

```
unary := (+ | -) unary | number | ref | call | ( expr )
call  := fname ( arg {, arg} )          fname := SUM | AVG | MIN | MAX   (case-insensitive)
arg   := ref : ref | expr
```

- A range `ref : ref` (whitespace allowed around the `:`) names the rectangle with those two cells as opposite corners, in either order (`B3:A1` is `A1:B3`). Ranges are allowed only as function arguments. Calls can be nested (`=SUM(A1:A3, MAX(B1:B2)) * 2`).
- `parse_formula` raises `FormulaError` for an unknown function name, a function name without `(`, a call with no arguments, and a `:` anywhere other than between the two references of an argument.
- `references` includes every cell of each range whose two corners are inside the sheet.

A call evaluates its arguments left to right and collects numbers from them:

- A range whose corners are both inside the sheet contributes its cells in row-major order. A cell holding a number is collected, an empty cell or a text cell is skipped, and a cell holding an error value makes that error the call's result. A range with a corner outside the sheet gives `#REF!`.
- An argument that is a single reference, with or without parentheses, is treated as a one-cell range, so text in it is skipped.
- Any other argument is evaluated as an expression. An error value becomes the call's result, text gives `#VALUE!`, and a number is collected.
- The call's result is the first error met in this order. Otherwise it is computed from the collected numbers:
  - `SUM` gives their sum: an `int` when all are `int`s, else a `float`, and `0` when there are none.
  - `AVG` gives their mean as a `float`, or `#DIV/0!` when there are none.
  - `MIN` and `MAX` give the smallest and largest number unchanged, or `0` when there are none.

A cell whose formula reads a range that contains the cell itself is on a cycle, like any other circular reference.
