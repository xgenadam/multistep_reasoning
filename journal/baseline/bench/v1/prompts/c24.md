Write a Python module `units.py` with a function `convert(value: float, from_unit: str, to_unit: str) -> float` that converts a quantity between units of length, mass and time, including composite units such as `m/s`, `km/h` and `kg*m/s^2`.

**Simple units** (exact factors to the base unit):
- length, base `m`: `mm` = 0.001, `cm` = 0.01, `m` = 1, `km` = 1000, `in` = 0.0254, `ft` = 0.3048, `yd` = 0.9144, `mi` = 1609.344;
- mass, base `kg`: `mg` = 0.000001, `g` = 0.001, `kg` = 1, `t` = 1000, `oz` = 0.028349523125, `lb` = 0.45359237;
- time, base `s`: `ms` = 0.001, `s` = 1, `min` = 60, `h` = 3600, `day` = 86400.

Unit names are case-sensitive.

**Composite units.** A unit expression is one or more factors joined by `*` or `/`, with no spaces. A factor is a simple unit, optionally followed by `^N` with a positive integer `N` (as in `s^2`). `^` applies only to its own factor, and `*` and `/` are applied from left to right, so `m/s*s` is the same as `m`, and `kg*m/s^2` is kilograms times metres per second squared.

**Conversion.** Both expressions are reduced to a scale factor and a dimension (the exponents of length, mass and time). `convert` returns `value * scale(from_unit) / scale(to_unit)` as a `float`.

**Errors.** Both exception classes subclass `ValueError`:
- `UnitError` for an unknown unit name or a malformed expression (an empty string, an empty factor as in `m//s`, a missing or non-positive exponent such as `m^`, `m^0` or `m^-1`, or spaces).
- `DimensionError` when the two expressions have different dimensions, as in `m` to `s` or `m` to `m^2`.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
