Write a Python module `jpath.py` for reading values out of nested JSON-like data (dicts, lists and scalars) with path strings such as `a.b[2].c`.

**Path syntax.** A path is a sequence of segments:
- A *name* is one or more characters other than `.`, `[`, `]` and `"`; it selects a key of a dict. The first segment may be a bare name; every later name is written after a `.`, as in `a.b`.
- `[N]` with an integer `N` (digits with an optional leading `-`, nothing else) selects a list element; negative indices count from the end as in Python. Brackets follow the previous segment directly (`a[0]`, `a[0][1]`), and a path may start with one (`[0].name`).
- `["..."]` is a quoted key, for keys that contain dots or other special characters, as in `a["x.y"].z`. Inside the quotes `\"` stands for `"` and `\\` for `\`; any other backslash is a syntax error.
- The empty path `""` has no segments and refers to the whole object.

Anything else is a syntax error: an empty name (`a..b`, `.a`, `a.`), `.` before a bracket (`a.[0]`), `[]`, `[1.5]`, `[x]`, an unclosed bracket or quote, or a `]` with no `[`.

**Functions.**
- `class PathError(LookupError)`, with an attribute `path`: the path string it was raised for.
- `parse(path: str) -> list[str | int]` returns the segments in order, names and quoted keys as `str` and indices as `int`; for example `parse('a["x.y"][-1].0')` is `['a', 'x.y', -1, '0']`. A syntax error raises `PathError`.
- `get(obj, path: str, default=<none>)` follows the path from `obj` and returns the value it reaches.
  - A `str` segment looks up that key in a `collections.abc.Mapping`. An `int` segment indexes a `list` or `tuple`. Any other combination counts as a missing value, so a name never indexes a list (`items.0` does not select `items[0]`), an index never looks up a dict key, and strings and other scalars are never indexed.
  - A missing value (an absent key, an out-of-range index or a combination above) returns `default` if a default was passed, including `default=None`, and raises `PathError` if none was passed.
  - A syntax error always raises `PathError`, even when a default was passed.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
