Write an expense splitter for shared trips and households in Python, as a package `split`: a group of people, expenses shared equally, by exact amounts or by percentages, everyone's balance, and a plan of payments that settles the group.

Layout:

```
split/__init__.py   re-exports parse_amount, format_amount, Equal, Exact, Percent, Expense, Group,
                    load_group, balances, format_balances, Transfer, settle, format_plan
split/model.py      parse_amount, format_amount, Equal, Exact, Percent, Expense, Group, load_group
split/balances.py   balances, format_balances
split/settle.py     Transfer, settle, format_plan
```

All money is an `int` number of cents. Every invalid input raises `ValueError`.

## Model (`split/model.py`)

- `parse_amount(text)` accepts digits optionally followed by `.` and one or two digits (`'12'`, `'12.5'`, `'0.05'`) and returns cents (`1200`, `1250`, `5`). `format_amount(cents)` returns the amount with exactly two decimals, with `-` for a negative amount: `1250` → `'12.50'`, `-5` → `'-0.05'`, `0` → `'0.00'`.
- Splits are frozen dataclasses:
  - `Equal(members=None)`: shared equally among the listed members, or among all the group's members (at the time the expense is added) if `None`;
  - `Exact(shares)`: a dict from member to cents; the shares must be ≥ 0 and add up to the expense's amount;
  - `Percent(shares)`: a dict from member to a percentage (an `int`, a `decimal.Decimal` or a decimal string such as `'33.5'`); each must be ≥ 0 and together they must add up to exactly 100.
- `Expense(description, paid_by, amount, split)` is a frozen dataclass; `amount` is in cents and must be > 0.
- `Group(members)` takes the member names (non-empty strings, no repeats).
  - `members` is the list of names, in the order added. `add_member(name)` adds one.
  - `add_expense(expense)` checks the expense (the payer and everyone in the split must be members; an `Equal` list must be non-empty with no repeats), computes its shares, stores it, and returns the shares: a dict from member to cents, with one key per participant, in the group's member order, adding up to the amount.
  - `add_payment(payer, payee, amount)` records money handed over directly (both members, different people, amount > 0).
  - `expenses` is the list of `(expense, shares)` pairs and `payments` the list of `(payer, payee, amount)` tuples, in the order added.
- Rounding, so that the shares always add up to the amount:
  - `Equal` among `n` people: everyone gets `amount // n`, and the remaining `amount % n` cents go one each to the first participants in alphabetical order of name.
  - `Percent`: everyone gets the floor of `amount × percentage / 100` (computed exactly, with `Decimal`), and the cents still missing go one each to the participants with the largest fractional parts of that product, ties broken alphabetically.
- `load_group(data)` builds a `Group` from a dict:

  ```python
  {"members": ["ana", "ben", "cai"],
   "expenses": [
       {"description": "Dinner", "paid_by": "ana", "amount": "90.00", "split": {"type": "equal"}},
       {"description": "Taxi", "paid_by": "ben", "amount": "20", "split": {"type": "equal", "members": ["ben", "cai"]}},
       {"description": "Hotel", "paid_by": "cai", "amount": "300", "split": {"type": "percent", "shares": {"ana": "50", "ben": "25", "cai": "25"}}},
       {"description": "Wine", "paid_by": "ana", "amount": "30", "split": {"type": "exact", "shares": {"ben": "10", "cai": "20.00"}}}],
   "payments": [{"from": "ben", "to": "ana", "amount": "15"}]}
  ```

  Amounts are strings parsed with `parse_amount`; percentages are strings. `expenses` and `payments` may be left out. Expenses and payments are added in the order listed, after all the members.

## Balances (`split/balances.py`)

- `balances(group)` returns a dict from every member, in alphabetical order, to their balance in cents: what they paid for expenses, minus their shares, plus payments they made, minus payments they received. Positive means the group owes them money. The balances add up to 0.
- `format_balances(bals)` returns one line per member in alphabetical order, `f"{name}: {amount}"`, where a positive amount is written with a leading `+` (`+12.50`), a negative one with `-` (`-0.05`), and zero as `0.00`. Each line ends with `"\n"`.

## Settling up (`split/settle.py`)

- `Transfer` is a `NamedTuple` with fields `payer`, `payee`, `amount` (cents).
- `settle(bals)` takes a balances dict (`ValueError` if it does not add up to 0) and returns the transfers that bring every balance to zero, chosen by this greedy rule: while any balance is non-zero, take the creditor with the largest positive balance and the debtor with the most negative balance (ties broken alphabetically in both cases); the debtor pays the creditor the smaller of the two amounts. The input dict is not changed.
- `format_plan(transfers)` returns one line per transfer, `f"{payer} pays {payee} {amount}"` with the amount as `format_amount` writes it, each ending with `"\n"`, or `"All settled.\n"` if there are none.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
