Write a Python module `toposort.py` with a function `toposort(graph) -> list[str]` that orders nodes so that every node comes after the nodes it depends on.

- `graph` is a mapping from a node to an iterable of the nodes it depends on. Nodes are strings. A node that appears only as a dependency, never as a key, is a node with no dependencies. A dependency listed more than once counts once. `graph` and its iterables are not modified.
- The result lists every node exactly once, each after all of its dependencies.
- Ties are broken lexicographically: at each step, of all the nodes not yet listed whose dependencies are all listed, the smallest (by Python's `<` on strings) comes next. So `toposort({'b': [], 'a': [], 'c': ['b']})` is `['a', 'b', 'c']`, and `toposort({'z': [], 'a': ['z']})` is `['z', 'a']`.
- If the dependencies contain a cycle, including a node that depends on itself, raise `CycleError`, a subclass of `ValueError` defined in the module. Its attribute `cycle` is a list of distinct nodes `[n1, n2, ..., nk]` forming a cycle in the graph: `n1` depends on `n2`, `n2` depends on `n3`, and so on, and `nk` depends on `n1`. A node that depends on itself gives `[n]`. If the graph has several cycles, any one of them will do.
- An empty graph gives `[]`.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
