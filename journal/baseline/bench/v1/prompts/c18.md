Write a Python module `slug.py` with a function `slugify(text: str, max_len: int = 50, existing=()) -> str` that turns a title into a URL slug.

Apply these steps in order:

1. Delete every apostrophe (`'` and `’`), so `Don't` becomes `Dont`.
2. Normalise with `unicodedata.normalize('NFKD', ...)` and drop every character that is not ASCII, so `Crème Brûlée` becomes `Creme Brulee` and `ﬁ` becomes `fi`.
3. Lower-case the result.
4. Replace every run of one or more characters that are not `a`–`z` or `0`–`9` with a single `-`, and strip `-` from both ends. If nothing is left, the slug is `untitled`.
5. If the slug is longer than `max_len`, shorten it: keep the longest prefix of at most `max_len` characters that ends just before a `-` (so the result ends on a whole word and has no trailing `-`). If even the first word is longer than `max_len`, cut it to its first `max_len` characters instead.
6. `existing` is a collection of slugs already in use. If the slug is in it, try `slug-2`, `slug-3`, and so on, and return the first one not in `existing`. The suffixed slug must also be at most `max_len` characters: for the suffix `-N`, the base slug from step 4 is shortened by the rule of step 5 to `max_len - len('-N')` characters before the suffix is added.

`slugify` raises `ValueError` if `max_len` is less than 1. It never modifies `existing`.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
