Firmware 2.0 for the Hearthline T2 is about to ship, and the manual must describe it. Firmware 2.0 adds three features and changes two. Please update the manual.

**New features** (each gets its own chapter, with the same three subsections as the others: How to, Settings, Troubleshooting):
1. **Open Window Detection.** If the room temperature drops by 2 °C or more within 5 minutes, the T2 assumes a window is open and pauses heating for 30 minutes, then resumes the normal schedule. Settings: Open window detection (on/off; default on), Pause length (15–60 minutes in 15-minute steps; default 30 minutes). Place this chapter after Eco Temperature.
2. **Smart Preheat.** The T2 learns how long the home takes to warm up and starts heating early so the target temperature is reached at the scheduled time, starting at most 2 hours early. Settings: Smart preheat (on/off; default off), Maximum early start (30 minutes to 2 hours in 30-minute steps; default 2 hours). Place this chapter after Weekly Schedule.
3. **Room Sensors.** Up to 6 optional wireless room sensors (each on one CR2032 coin battery, about 1 year of life) can be added in the app. The T2 then controls the heating on the average temperature of the sensors selected for each schedule period. Settings: Sensors (up to 6), Sensors used per period (any combination; default all), Sensor name (up to 20 characters). Place this chapter after Multi-User Access.

**Changed features:**
1. **Boost.** The boost duration is now any length from 15 to 180 minutes in 15-minute steps (default still 60 minutes). Update the How to steps, the Settings table and the Troubleshooting for Boost.
2. **Multi-User Access.** A home can now have up to 12 users, and there is a fourth role, Installer, which can view settings and error history but cannot see the household's location or energy reports. Update the chapter accordingly.

**Other changes:**
- Add a new error code E6: room sensor offline (what to do: check the sensor's battery, then move it closer to the wall unit). The Error Codes table now has exactly six codes.
- Add one line near the start of the manual saying it covers firmware 2.0 and how to check the firmware version (Menu > Settings > About).
- Add the room sensors' battery and the 6-sensor limit to the Specifications table.
