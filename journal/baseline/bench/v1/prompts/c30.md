Write a Python module `money.py` for exact money arithmetic in cents with `decimal.Decimal`.

- `to_cents(x) -> Decimal` accepts an `int`, a `Decimal` or a `str` holding a decimal number (surrounding whitespace allowed) and returns it rounded to two decimal places with banker's rounding (`ROUND_HALF_EVEN`), so `'2.675'` gives `Decimal('2.68')`, `'2.665'` gives `Decimal('2.66')`, and `5` gives `Decimal('5.00')`. A `float` or `bool` (or any other type) raises `TypeError`; a string that is not a finite decimal number (including `'NaN'` and `'Infinity'`) raises `ValueError`.
- `allocate(amount, ratios) -> list[Decimal]` splits `amount` (first passed through `to_cents`) into one part per ratio, in the same order, so that the parts always add up exactly to the amount. `ratios` is a non-empty list of non-negative `int`s or `Decimal`s with a positive sum; otherwise `ValueError`. Use the largest-remainder rule:
  1. Work in whole cents. For a non-negative amount of `C` cents, each part's exact share is `C * r / sum(ratios)` cents; every part first gets that share rounded down to a whole cent.
  2. The cents still left over are handed out one at a time to the parts with the largest fractional remainders (the share minus its rounded-down value). When remainders are equal, the part that comes earlier in the list gets the cent first.
  3. A negative amount is allocated as the negation of the allocation of its absolute value.

  Each part is a `Decimal` with exactly two decimal places. For example, `allocate('100', [1, 1, 1])` is `[Decimal('33.34'), Decimal('33.33'), Decimal('33.33')]` and `allocate('0.05', [3, 7])` is `[Decimal('0.02'), Decimal('0.03')]`.
- `split_even(amount, n: int) -> list[Decimal]` is `allocate(amount, [1] * n)`; `ValueError` if `n < 1`.
- `format_money(amount) -> str` formats `to_cents(amount)` with a comma between groups of three digits and exactly two decimals, with a leading `-` for negative amounts: `format_money('-1234567.891')` is `'-1,234,567.89'`, and `format_money('-0.001')` is `'0.00'` (no sign on zero).

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
