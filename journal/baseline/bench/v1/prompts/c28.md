Write a Python module `events.py` with a small synchronous event emitter.

- `class EmitError(Exception)` has an attribute `errors`: a list of `(listener, exception)` pairs in the order the listeners were called.
- `class Emitter` with:
  - `on(event, listener)` registers `listener` (a callable) for the hashable `event` and returns `listener`. The same listener may be registered more than once and is then called once per registration.
  - `once(event, listener)` is like `on`, but the registration is removed just before its first call, so the listener runs at most once even if it emits the same event again from inside itself. It also returns `listener`.
  - `off(event, listener=None) -> int` removes the earliest remaining registration of `listener` for `event` (whether made with `on` or `once`) and returns 1, or returns 0 if there is none. With `listener=None` it removes every registration for `event` and returns how many it removed.
  - `emit(event, *args, **kwargs) -> int` calls the listeners registered for `event` in registration order, each with `*args, **kwargs`, and returns the number of calls made. The set of listeners is fixed when `emit` starts: a listener registered during the emit is not called by it, and a registration removed during the emit is not called by it if its turn has not come yet. If listeners raise exceptions (subclasses of `Exception`), the remaining listeners still run; after the last one, `emit` raises `EmitError` with every failure. Calls that raised still count as calls made.
  - `listeners(event) -> list` returns the registered listeners for `event` in order, one entry per registration, as a new list.
- Emitting an event with no listeners returns 0.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
