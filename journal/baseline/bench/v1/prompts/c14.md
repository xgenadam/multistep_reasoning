Write a Python module `mdtable.py` with a function `format_table(rows, headers, align=None) -> str` that renders a padded GitHub-flavoured Markdown table.

Arguments:
- `headers` is a non-empty sequence of column headers; `rows` is a sequence of rows, each a sequence with exactly one cell per header. Otherwise raise `ValueError`.
- `align` is `None` (every column left-aligned) or a sequence with one entry per column, each `'left'`, `'right'` or `'center'`. A wrong length or an unknown entry raises `ValueError`.

Cell text:
- Each header and cell is converted with `str()`, except that `None` becomes the empty string.
- Every `|` in the text is escaped as `\|`, and every newline (`\n`, or `\r\n` as a whole) becomes `<br>`.
- Width is measured with `len()` on the escaped text; the display width of wide or combining characters is deliberately ignored.

Layout:
- A column's width is the longest escaped text in it, header included, but at least 3.
- The output has a header line, a separator line and one line per row, joined with `\n` and with no trailing newline.
- Every line is `| ` + the column texts joined by ` | ` + ` |`. In the header and row lines each text is padded with spaces to its column's width: on the right for `left`, on the left for `right`, and for `center` the padding is split with the smaller half on the left (`'ab'` centred in width 5 is `' ab  '`).
- In the separator line each column is a run of dashes as wide as the column, with a `:` replacing the first dash for `left`, the last dash for `right`, and both for `center`. For a width of 5: `:----`, `----:`, `:---:`.

Example: `format_table([['apple', 3], ['kiwi', 12]], ['fruit', 'qty'], ['left', 'right'])` returns

```
| fruit | qty |
| :---- | --: |
| apple |   3 |
| kiwi  |  12 |
```

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
