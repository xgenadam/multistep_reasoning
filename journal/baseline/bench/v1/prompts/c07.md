Write a Python module `ini.py` that parses INI-style configuration text.

Interface:
- `parse(text: str) -> Config` parses the whole text or raises `ParseError`.
- `class ParseError(ValueError)` has an attribute `lineno`, the 1-based number of the offending line, and its message contains `line N` with that number.
- `Config` has these methods. Section names and keys are case-sensitive.
  - `sections() -> list[str]`: the section names in the order they appear.
  - `keys(section) -> list[str]`: the keys of a section in the order they appear; `KeyError` if there is no such section.
  - `get(section, key, default=None) -> str | None`: the value as a string, or `default` if the section or the key is missing.
  - `getint(section, key, default=None)`: the value as an `int`. It accepts an optional sign and decimal digits only (`'42'`, `'-7'`, `'+3'`); anything else, such as `'4.0'` or `'0x10'` or `''`, raises `ValueError`. A missing section or key returns `default`.
  - `getbool(section, key, default=None)`: `True` for `true`, `yes`, `on`, `1` and `False` for `false`, `no`, `off`, `0`, in any letter case; anything else raises `ValueError`. A missing section or key returns `default`.
  - `getlist(section, key, default=None) -> list[str]`: the value split on commas, each item stripped of surrounding whitespace, empty items dropped (so `'a, b,,c ,'` gives `['a', 'b', 'c']` and `''` gives `[]`). A missing section or key returns `default`.

Syntax, line by line (lines are split with `str.splitlines()`):
- A blank line (empty or only whitespace) is ignored.
- A comment is a line whose first non-whitespace character is `;` or `#`. It is ignored. There are no inline comments: a `;` or `#` later in a line is part of the value (`url = http://host/#top` has the value `http://host/#top`).
- A section header is a line `[name]` that is not indented. Whitespace inside the brackets around the name and after the `]` is allowed; the name is stripped and must not be empty.
- A key line is `key = value`, split at the first `=`. The key and the value are stripped of surrounding whitespace; the value may be empty, the key may not. A key line must not be indented, and must come after a section header.
- A continuation line is an indented line (it starts with a space or a tab) that is not blank and not a comment, and that comes directly after a key line or another continuation line, with no blank or comment line in between. Its stripped text is appended to the value with a single `\n` between them. So `cmd = run` followed by `    --fast` gives `'run\n--fast'`.

Errors, each a `ParseError` for the line where it happens:
- a key line before any section header;
- the same key twice in one section;
- the same section header twice;
- an indented line that is not a valid continuation line;
- an empty key or an empty section name;
- any other line that is not one of the forms above (no `=` and not a header, for example).

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
