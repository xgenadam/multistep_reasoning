Write a Python module `roman.py` that converts between integers and Roman numerals.

- `to_roman(n: int) -> str` returns the standard (canonical) uppercase Roman numeral for `n`, using subtractive notation (`IV`, `IX`, `XL`, `XC`, `CD`, `CM`): for example `to_roman(1994) == 'MCMXCIV'` and `to_roman(3999) == 'MMMCMXCIX'`.
  - If `n` is not an `int`, or is a `bool`, raise `TypeError`.
  - If `n` is outside 1 to 3999, raise `ValueError`.
- `from_roman(s: str) -> int` returns the value of a numeral. It accepts exactly the 3999 strings that `to_roman` can return and nothing else, so it is the inverse of `to_roman`.
  - If `s` is not a `str`, raise `TypeError`.
  - Every other string raises `ValueError`. That includes the empty string, lowercase or mixed-case numerals (`'xiv'`), surrounding or inner whitespace, characters other than `IVXLCDM`, and non-canonical forms such as `'IIII'`, `'VV'`, `'VX'`, `'IC'`, `'XM'`, `'IIV'`, `'MMMM'` and `'CMCM'`.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
