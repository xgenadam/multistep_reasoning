Write a Python module `paths.py` with single-source shortest paths over a weighted directed graph.

- A graph is a dict mapping each node to a dict of its outgoing edges, `{neighbour: weight}`, as in `{'a': {'b': 2, 'c': 5}, 'b': {'c': 1}}`. Nodes are hashable. A node that appears only as an edge target (like `'c'` above) is still a node of the graph. Weights are `int` or `float` and may be 0.
- `dijkstra(graph, src) -> tuple[dict, dict]` returns `(dist, prev)`:
  - `dist` maps **every** node of the graph to the length of the shortest path from `src`, or `None` if the node is unreachable; `dist[src]` is 0.
  - `prev` maps every node to its predecessor on a shortest path from `src`, or `None` for `src` itself and for unreachable nodes.
  - If several shortest paths exist, any one of them may be used.
  - Raises `KeyError` if `src` is not a node of the graph, and `ValueError` if any edge anywhere in the graph has a negative weight (even one that cannot be reached from `src`), before doing any work.
- `shortest_path(graph, src, dst) -> list | None` returns the nodes of a shortest path from `src` to `dst`, both included (`[src]` when `src == dst`), or `None` if `dst` is unreachable. It raises `KeyError` if either node is not in the graph, and `ValueError` for negative weights as above.
- Use a binary heap (`heapq`) so that a graph with `E` edges takes O(E log E) time; nodes need not be comparable with each other.
- The graph is never modified.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
