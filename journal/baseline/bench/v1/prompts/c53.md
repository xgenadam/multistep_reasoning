Write a small job queue with retries in Python, as a package `jobs`. It runs in a simulation: time comes from an injected clock, workers process jobs instantly, and failed jobs are retried with exponential backoff and jitter from a seeded random generator, so every run is reproducible. Jobs that keep failing end up in a dead-letter list.

Layout:

```
jobs/__init__.py   re-exports RetryPolicy, PermanentError, Job, JobQueue, ManualClock, Worker,
                   Event, run_until_idle
jobs/retry.py      RetryPolicy, PermanentError
jobs/queue.py      Job, JobQueue
jobs/worker.py     ManualClock, Event, Worker, run_until_idle
```

## Retry policy (`jobs/retry.py`)

`RetryPolicy(max_attempts=5, base=1.0, factor=2.0, max_delay=60.0, jitter=0.0)` is a frozen dataclass. It raises `ValueError` unless `max_attempts >= 1`, `base > 0`, `factor >= 1`, `max_delay >= base` and `0 <= jitter < 1`.

- `backoff(attempt)`: for the `attempt`-th failed attempt (1-based), `min(max_delay, base * factor ** (attempt - 1))`. `ValueError` if `attempt < 1`.
- `delay(attempt, rng)`: `backoff(attempt) * (1 - jitter + 2 * jitter * u)`, where `u = rng.random()`. It calls `rng.random()` exactly once per call, even when `jitter` is 0.
- `should_retry(attempt)`: whether a job whose `attempt`-th attempt just failed gets another one: `attempt < max_attempts`.

`PermanentError` is an `Exception` subclass. A handler that raises it is never retried.

## Queue (`jobs/queue.py`)

`Job` is a dataclass with fields `id`, `payload`, `status` (`'pending'`, `'running'`, `'done'` or `'dead'`), `attempts` (how many times it has been claimed), `available_at` (the time from which it may be claimed) and `last_error` (a string or `None`).

`JobQueue(clock)` takes a function with no arguments that returns the current time; the queue reads the time only by calling it.

- `submit(job_id, payload, delay=0.0)` adds a pending job available from `clock() + delay` and returns it. A repeated `job_id` or a negative `delay` raises `ValueError`.
- `claim()` returns the pending job with the earliest `available_at` that is not later than `clock()`, ties broken by submission order, after marking it `'running'` and adding 1 to its `attempts`; or `None` if no job is ready.
- `complete(job_id)` marks a running job `'done'`.
- `retry(job_id, error, at)` makes a running job `'pending'` again, available from time `at`, with `last_error = error`.
- `bury(job_id, error)` marks a running job `'dead'` with `last_error = error` and adds it to the dead letters.
- `complete`, `retry` and `bury` raise `KeyError` for an unknown id and `ValueError` if the job is not running.
- `get(job_id)` returns the job (`KeyError` if unknown); `dead_letters()` returns a new list of the dead jobs in the order they died; `counts()` returns `{'pending': …, 'running': …, 'done': …, 'dead': …}` with all four keys; `next_available()` returns the earliest `available_at` among pending jobs, or `None` if there are none.

## Workers and simulation (`jobs/worker.py`)

- `ManualClock(start=0.0)` is callable and returns the current time. `advance(dt)` moves it forward (`ValueError` if `dt < 0`); `set(t)` jumps to `t` (`ValueError` if `t` is earlier than now).
- `Event` is a `NamedTuple` with fields `time`, `worker`, `job_id`, `attempt`, `outcome` (`'done'`, `'retry'` or `'dead'`) and `delay` (the retry delay for `'retry'`, otherwise `None`).
- `Worker(name, queue, handler, policy, rng, clock)`. `step()` claims a job (returning `None` if there is none) and calls `handler(job.payload)`:
  - if it returns, the job is completed: outcome `'done'`;
  - if it raises `PermanentError`, the job is buried: outcome `'dead'`;
  - if it raises any other `Exception` and `policy.should_retry(job.attempts)`, then `delay = policy.delay(job.attempts, rng)` and the job is retried at `clock() + delay`: outcome `'retry'`; otherwise it is buried: outcome `'dead'`.

  The error stored is `f'{type(exc).__name__}: {exc}'`. `step()` returns the `Event`, whose `time` is `clock()` when the job was claimed and whose `attempt` is the job's `attempts` after the claim.
- `run_until_idle(queue, workers, clock, max_steps=10000)` runs rounds: in each round every worker, in list order, calls `step()` once. If a round produced no event, then if `queue.next_available()` is `None` the run ends, and otherwise the clock is `set` to that time and the rounds go on. It returns the list of all events in the order they happened, and raises `RuntimeError` as soon as more than `max_steps` events have happened.
