Write a Python module `pq.py` with a class `TaskQueue`, a priority queue of tasks that supports changing and removing tasks efficiently.

- Tasks are any hashable values and each task is in the queue at most once. Priorities are numbers; **lower numbers come out first**, and tasks with equal priority come out in the order they were pushed (first in, first out).
- `push(task, priority)` adds a task. Pushing a task that is already queued raises `ValueError`.
- `pop()` removes and returns `(task, priority)` for the next task. `peek()` returns the same pair without removing it. Both raise `IndexError` on an empty queue.
- `reprioritize(task, priority)` changes a queued task's priority. Among tasks of equal priority it then counts as if it had just been pushed, even if the priority is unchanged. It raises `KeyError` if the task is not queued.
- `remove(task)` takes a task out of the queue; `KeyError` if it is not queued. A removed task can be pushed again later.
- `len(queue)` is the number of queued tasks, `task in queue` tells whether a task is queued, and `priority(task)` returns its current priority (`KeyError` if not queued).
- `push`, `pop`, `reprioritize` and `remove` must take O(log n) amortised time; a heap with lazy deletion of stale entries is fine.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
