Write an audit summary for the product director, who will decide what goes into the next release. Use these markdown sections: Summary, How we prioritised, Tier 1: fix before the next release, Tier 2: fix this quarter, Tier 3: schedule in the backlog, Total effort.

- Assign every finding to exactly one tier with this rule: Tier 1 is any Level A failure on the checkout or sign-in pages; Tier 2 is any other Level A failure, or a Level AA failure on the checkout or sign-in pages; Tier 3 is everything else.
- In each tier section, list its findings as bullet points, one per finding and in ID order, each starting with the finding's ID (for example "F7"), then the WCAG criterion, then one sentence on who is affected and how.
- End each tier section with a line, not a bullet, reading "Tier effort: N hours", where N is the sum of that tier's estimates.
- Total effort: the total hours across all tiers, and a suggested order of work within Tier 1.

Write plainly for a non-specialist reader; explain the impact on real users rather than quoting the standard. Aim for about 700-900 words.
