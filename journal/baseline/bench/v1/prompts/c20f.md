Extend `jpath.py` with writing, deleting and wildcards. Everything from the previous version keeps working exactly as before for paths without wildcards.

- **Wildcard syntax.** `[*]` is a new segment that matches every element of a list or tuple (in order) or every value of a mapping (in insertion order); it matches nothing on any other value. `parse` returns it as the module constant `WILDCARD` (a unique object, not a string). A quoted `["*"]` is still an ordinary key `'*'`.
- **`get` with wildcards.** When a path contains at least one `[*]`, `get` returns a list of every value the path reaches, in order (for nested wildcards, ordered by the first wildcard's position, then by the next). Branches where the rest of the path is missing are skipped. Such a call never raises for missing values and ignores `default`; it returns `[]` when nothing matches. Syntax errors still raise `PathError`.
- **`set(obj, path, value) -> None`** stores `value` at `path`, changing `obj` in place:
  - The path must have at least one segment and no wildcard; otherwise `PathError`.
  - Every segment but the last is followed as `get` does, through mappings, lists and tuples. When the value at a segment is missing, a new container is created there: a `list` if the next segment is an index, a `dict` if it is a key. A container can only be created, and the final value only stored, inside a `dict` (for a key segment) or a `list` (for an index segment).
  - In a list, an index from `-len` to `len - 1` refers to an existing element (which is replaced at the last segment), and index `len` appends. Any other index raises `PathError`, so a newly created list only accepts index 0: `set({}, 'a[0].b', 1)` gives `{'a': [{'b': 1}]}`, and `set({}, 'a[1]', 1)` raises.
  - Any other combination raises `PathError`: a key segment on a list, an index segment on a dict, or any segment on a string, a number, `None` or a tuple that would have to change.
  - When `set` raises, `obj` is left exactly as it was.
- **`delete(obj, path)`** removes the value at `path` from its parent `dict` or `list` and returns it. Negative indices work as in `get`. It raises `PathError` if the path is empty, contains a wildcard, the value is missing, or the parent is not a `dict` or `list`.

Use only the Python 3.12 standard library. Give the complete updated files, each in its own fenced code block, with the file's path on the line just before the block.
