Write a small board-game package `games/` with tic-tac-toe, connect-four and one game-tree search that plays both. There are four files: `games/__init__.py`, `games/tictactoe.py`, `games/connect4.py` and `games/search.py`.

## The game interface

Both games are immutable state objects with the same interface, and the search uses only this interface:
- `player`: the player to move, `'X'` or `'O'`. `X` always moves first.
- `moves() -> list`: the legal moves in ascending order; `[]` once the game is over.
- `play(move)`: a new state with the move made (the original is unchanged). An illegal move, including any move after the game is over, raises `ValueError`.
- `winner()`: `'X'`, `'O'` or `None`.
- `is_over() -> bool`: true when there is a winner or the board is full.
- `str(state)`: the board, one line per row from the top, joined with `'\n'` (no trailing newline), `X`, `O` and `.` for an empty cell.
- States compare equal (and hash equal) when their boards are equal.

## `games/tictactoe.py`

`TicTacToe(board: str = '.........')`. The board is 9 characters, the squares 0–8 row by row from the top left. The constructor raises `ValueError` if the length is not 9, if a character is not `X`, `O` or `.`, or if the counts are impossible (`X` must have the same number of marks as `O` or one more). The player to move follows from the counts. A move is a square number; a square that is taken or outside 0–8 is illegal. Attribute `board` holds the string. `TicTacToe.from_moves(moves)` (class method) plays the given squares in order from the empty board, raising `ValueError` at the first illegal one.

## `games/connect4.py`

`ConnectFour(columns: int = 7, rows: int = 6)` is an empty board (`ValueError` if either is below 1), with the attributes `columns` and `rows`. A move is a column number, 0 being the leftmost; the piece falls to the lowest empty cell of that column. A full column or a number outside the board is illegal. A player wins with four of their pieces in a line horizontally, vertically or on either diagonal; on boards too small for four in a line, a full board is a draw.
- `ConnectFour.from_moves(moves, columns=7, rows=6)` (class method) plays the given columns in order from an empty board, raising `ValueError` at the first illegal one.
- `cell(column, row) -> str` gives `'X'`, `'O'` or `'.'`, with row 0 at the bottom; `IndexError` outside the board.
- `str(state)` shows the top row first.

`evaluate(state) -> int` is a heuristic for depth-limited search, scored for `state.player`. It looks at every *window*, a line of four cells (horizontal, vertical or diagonal) that fits on the board. A window holding pieces of only one player, `n` of them (1 to 3), is worth `n * n`: positive if that player is `state.player`, negative otherwise. Empty windows, windows holding both players' pieces and windows with four pieces are worth 0. The result is the sum over all windows.

## `games/search.py`

Negamax search with alpha-beta pruning.

`SearchResult` is a frozen dataclass with `score: float`, `move` and `nodes: int`.

`search(state, depth=None, evaluate=None) -> SearchResult`:
- `score` is the value of `state` for the player to move there, under best play by both sides. `move` is the move that achieves it (`None` if the game is over or `depth` is 0). `nodes` is the number of states examined, the root included; a state reached by two move orders counts each time.
- A finished game is scored for the player to move in it: 0 for a draw, and `-(1000 - ply)` for a loss, where `ply` is the number of moves between the root and that state. A quicker win therefore scores higher than a slower one, and a slower loss higher than a quicker one.
- `depth` is the number of moves to look ahead (`None`: no limit). A state reached at the depth limit that is not finished is scored `evaluate(state)`, the value for the player to move in it; with no `evaluate` it scores 0.
- When several moves have the same best value, the one that comes first in `moves()` is chosen.
- Alpha-beta pruning must be used: a complete search of the empty tic-tac-toe board examines far fewer than its 549,946 states (fewer than 100,000).

`best_move(state, depth=None, evaluate=None)` returns `search(...).move` and raises `ValueError` if the game is over.

Players are functions `agent(state) -> move`:
- `search_agent(depth=None, evaluate=None)` returns an agent that plays `best_move(state, depth, evaluate)`.
- `random_agent(seed)` returns an agent that plays `rng.choice(state.moves())` with its own `rng = random.Random(seed)`, created once when the agent is made.
- `play_game(state, agents: dict) -> tuple[final_state, list]` asks `agents[state.player]` for a move until the game is over and returns the final state and the list of moves played. An illegal move raises `ValueError` from `play`.

`games/__init__.py` re-exports `TicTacToe`, `ConnectFour`, `SearchResult`, `search`, `best_move`, `search_agent`, `random_agent` and `play_game`, and the connect-four heuristic as `connect4_evaluate`.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
