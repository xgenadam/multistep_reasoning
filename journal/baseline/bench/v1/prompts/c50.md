Write a small text-adventure engine in Python, as a package `adventure`. A world is loaded from a plain dict, the player types commands, and a game can be saved to JSON and loaded again.

Layout:

```
adventure/__init__.py   re-exports World, WorldError, Room, Item, parse, Command, ParseError, Game, SaveError
adventure/world.py      DIRECTIONS, Room, Item, World, WorldError
adventure/parser.py     Command, ParseError, parse(line)
adventure/game.py       Game, SaveError
```

## World (`adventure/world.py`)

`DIRECTIONS = ('north', 'south', 'east', 'west', 'up', 'down')`. `World.from_dict(data)` builds a world from a dict like this:

```python
{
    "start": "hall",
    "rooms": {
        "hall": {"name": "Great Hall", "description": "A draughty hall.",
                 "exits": {"north": "library"}, "items": ["lamp", "statue"]},
        "library": {"name": "Library", "description": "Dusty shelves.",
                    "exits": {"south": "hall"}},
    },
    "items": {
        "lamp": {"name": "brass lamp", "description": "A dented brass lamp."},
        "statue": {"name": "statue", "description": "Far too heavy.", "portable": False},
    },
}
```

- `exits` and `items` may be left out (no exits, no items). `portable` defaults to `True`.
- `Room` is a frozen dataclass with fields `id`, `name`, `description`, `exits` (a dict from direction to room id) and `items` (a tuple of item ids: where the items start). `Item` is a frozen dataclass with fields `id`, `name`, `description`, `portable`.
- A `World` has the attributes `start` (a room id), `rooms` (a dict from id to `Room`) and `items` (a dict from id to `Item`). A world never changes once built.
- `from_dict` raises `WorldError` (a subclass of `ValueError`) if `start` is missing or is not a room, a room lacks a `name` or `description`, an exit uses a direction not in `DIRECTIONS` or leads to an unknown room, a room lists an unknown item, or an item is listed more than once (in one room or across rooms). An item that no room lists is allowed; it is simply nowhere.

## Parser (`adventure/parser.py`)

`Command` is a `NamedTuple` with fields `verb` and `arg` (a string or `None`). `parse(line)` lower-cases the line, splits it on whitespace, removes every `the`, `a` and `an` after the first word, and returns a `Command`; `arg` is the remaining words joined with single spaces. It raises `ParseError` (a subclass of `ValueError`) whose `str()` is exactly the message shown below.

| Input | Result |
| --- | --- |
| a direction, or its first letter (`north`, `n`, `up`, `u`, …) | `Command('go', 'north')` and so on (full direction name) |
| `go DIR` (DIR as above) | `Command('go', DIR as full name)` |
| `take X`, `get X` | `Command('take', X)` |
| `drop X` | `Command('drop', X)` |
| `look`, `l` | `Command('look', None)` |
| `look X`, `look at X`, `examine X`, `x X` | `Command('look', X)` |
| `inventory`, `inv`, `i` | `Command('inventory', None)` |

Errors, with their exact messages:

- an empty or all-whitespace line: `Say something.`
- an unknown first word: `I don't know the word "WORD".` (the word as lower-cased)
- `go` with nothing after it: `Go where?`
- `go` followed by something that is not a direction: `"WORDS" is not a direction.` (the rest of the line, as lower-cased and joined)
- `take`/`get`, `drop`, or `examine`/`x`/`look at` with nothing left after removing articles: `Take what?`, `Drop what?`, `Examine what?`
- anything after a direction word or after `inventory`/`inv`/`i`: `I don't understand that.`

## Game (`adventure/game.py`)

`Game(world)` starts a game in `world.start` with an empty inventory and every item where its room lists it. Two games made from the same world never affect each other. Properties: `room` (the current room id), `inventory` (a new list of item ids, in the order they were taken) and `moves` (the number of successful moves). `items_in(room_id)` returns a new list of the item ids now in that room, in order.

`do(line)` runs one command and returns the response text. It never raises for any input; a `ParseError` returns its message. An item *matches* the command's `X` when `X` equals the item's id or the item's name lower-cased. Responses, exactly:

- `look`: the room description, made of these lines joined with `"\n"`:
  - the room's name;
  - its description;
  - `Exits: ` and the directions that have exits, in `DIRECTIONS` order, joined with `, `, then `.`; or `Exits: none.`;
  - only if the room holds items: `You see: ` and their names in room order, joined with `, `, then `.`.
- `look X`: the description of a matching item in the room or in the inventory (the room is searched first); otherwise `You see no X here.`
- `go DIR`: if the room has that exit, the player moves there, `moves` goes up by 1, and the response is the new room's `look` text. Otherwise `You can't go that way.`
- `take X`: if a matching item is in the room: `You can't take the NAME.` when it is not portable; otherwise it moves to the end of the inventory and the response is `Taken: NAME.` If no matching item is in the room but one is in the inventory: `You already have the NAME.` Otherwise `You see no X here.`
- `drop X`: if a matching item is in the inventory, it moves to the end of the current room's items: `Dropped: NAME.` Otherwise `You aren't carrying that.`
- `inventory`: `You are carrying: ` and the names in inventory order, joined with `, `, then `.`; or `You are carrying nothing.`

Here `NAME` is the item's `name` and `X` is the argument as parsed.

**Saving.** `save()` returns a JSON string of an object with exactly these keys: `"version": 1`, `"room"`, `"inventory"` (a list of item ids), `"items"` (an object with one key per room of the world, mapping to the list of item ids in that room, in order) and `"moves"`. `Game.load(world, text)` is a class method that returns a game in exactly the saved state (a room of the world that has no key under `"items"` holds no items); it raises `SaveError` (a subclass of `ValueError`) if the text is not JSON or not an object, a key is missing, `version` is not 1, the room or a room key is not in the world, an item id is not in the world, an item appears more than once across the inventory and the rooms, or `moves` is not a non-negative integer.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
