I teach a Year 5 class of 28 pupils and need a plan for a 45-minute maths lesson on equivalent fractions. The pupils can already name halves, quarters and thirds, but about a third of the class still finds fractions on a number line confusing. Every pair has a set of fraction strips and every pupil has a mini whiteboard.

Two parts of the lesson are fixed: it opens with a 5-minute warm-up recapping halves and quarters, and it closes with an 8-minute exit ticket. Plan four activities in between; the paired fraction-strip activity should be the longest of the four.

Write the plan for a colleague who will teach the lesson from it while I'm away, so it must be clear without me there. Use these markdown section headings: Learning objectives, Materials, Lesson timeline, Exit ticket, Differentiation.

- Learning objectives: exactly three, as bullet points.
- Lesson timeline: a table with the columns Activity, Minutes and What happens, one row per activity (six activities, counting the warm-up and the exit ticket), followed by a final row labelled Total. The minutes must add up to exactly 45.
- Exit ticket: exactly five numbered questions that check equivalent fractions, each with its expected answer on the line beneath it (not as a separate numbered list).
- Differentiation: how to support the pupils who struggle with the number line and how to stretch the fastest finishers.

Aim for about 500-700 words.
