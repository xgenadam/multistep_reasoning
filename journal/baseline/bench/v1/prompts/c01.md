Write a command-line tool `wordcount.py` that counts lines, words and characters in text files and prints them as an aligned table.

Usage: `python wordcount.py FILE [FILE ...]`. At least one FILE is required; with none, print a usage message that contains the word `usage` to standard error and exit with status 2.

Counting, per file:
- Read the file as UTF-8 with no newline translation, so `\r\n` counts as two characters.
- `lines`: the number of `\n` characters, plus one if the file is not empty and does not end with `\n`. An empty file has 0 lines.
- `words`: the number of maximal runs of non-whitespace characters (what `str.split()` with no arguments returns).
- `chars`: the number of characters (code points, not bytes), newlines included.

Output on standard output:
- A header row, then one row per readable file in the order given on the command line, then a `total` row only when two or more rows were printed for files. The total row sums the file rows.
- Each row has four columns: `lines`, `words`, `chars` and `file`. The header row's cells are exactly those four words. The `file` cell is the path exactly as given on the command line; the total row's `file` cell is `total`.
- The three number columns are right-aligned, each padded with spaces on the left to the width of the widest cell in that column, header included. The `file` column is last and is not padded. Columns are separated by exactly two spaces, and no line has trailing spaces.

For example, `python wordcount.py a.txt notes/b.txt` might print:

```
lines  words  chars  file
    3     12     61  a.txt
  120    950   5210  notes/b.txt
  123    962   5271  total
```

Errors: a FILE that does not exist or is not a regular file (a directory, for instance) is reported on standard error as the line `wordcount.py: cannot read FILE` (with FILE as given) and left out of the table and the total. The other files are still counted. If no FILE was readable, nothing at all is printed on standard output. The exit status is 1 if any FILE could not be read, otherwise 0, and nothing is written to standard error on success.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
