Write a small regular-expression engine in Python, as a package `rx`. Patterns are parsed into an AST, the AST is compiled into a Thompson NFA, and matching simulates the NFA over the text (tracking the set of active states, with no backtracking), so matching time is linear in the length of the text.

Layout:

```
rx/__init__.py   re-exports parse, compile, match, search, findall, RegexError and the AST classes
rx/parse.py      the AST classes, RegexError, parse(pattern)
rx/nfa.py        NFA, compile(pattern_or_ast), and the functions match, search, findall
```

## Syntax

- Any character other than `. * + ? | ( ) [ \` is a literal, including whitespace and a `]` outside a class.
- `.` matches any single character except `"\n"`.
- `\` followed by any character is that character as a literal (`\.`, `\*`, `\\`, `\[`, …). A `\` at the end of the pattern is an error.
- `[...]` is a character class: single characters and ranges `a-z` (both ends included). A `^` right after `[` negates the class (it then matches any character, including `"\n"`, that is not listed). A `-` is a literal when it is the first item (after any `^`) or the last item. Inside a class, `\` escapes the next character, and every other character, including `.`, `*`, `(` and `|`, is literal. A class must list at least one item.
- `*`, `+`, `?` apply to the atom just before them: a literal, `.`, a class or a parenthesised group.
- Concatenation binds tighter than `|`. `(...)` groups. An empty alternative or an empty group (`a|`, `|a`, `()`) matches the empty string, and the empty pattern matches the empty string.

## AST (`rx/parse.py`)

Frozen dataclasses, compared by value:

- `Empty()`: matches the empty string.
- `Literal(char: str)`.
- `AnyChar()`: the `.`.
- `CharClass(items: tuple[tuple[str, str], ...], negated: bool)`: each item is a `(low, high)` pair in the order written; a single character `c` is `(c, c)`.
- `Concat(items: tuple)`: two or more nodes, in order.
- `Alt(options: tuple)`: two or more nodes, left to right. `a|b|c` is one `Alt` with three options.
- `Star(node)`, `Plus(node)`, `Optional(node)`: the quantifiers.
- `Group(node)`: a parenthesised sub-pattern.

A sequence of one node is that node, never a one-item `Concat`; an empty sequence is `Empty()`. So `parse('ab*')` is `Concat((Literal('a'), Star(Literal('b'))))`, `parse('(a|)')` is `Group(Alt((Literal('a'), Empty())))` and `parse('')` is `Empty()`.

`parse(pattern: str)` returns the AST or raises `RegexError(message, position)`, a subclass of `ValueError` with attributes `message` and `position` (a 0-based index into the pattern):

| Error | `position` |
| --- | --- |
| a quantifier with nothing to repeat (at the start of the pattern, of a group or of an alternative, or right after another quantifier) | the quantifier |
| a `)` with no matching `(` | that `)` |
| a `(` that is never closed | that `(` (if several are unclosed, the last one opened) |
| a `[` that is never closed, or an empty class `[]` / `[^]` | that `[` |
| a range whose low end is greater than its high end, like `z-a` | the low end's character |
| a `\` at the end of the pattern | that `\` |

When a pattern has several errors, the one reported is the first one met reading left to right, except that an unclosed `(` is reported only when the end of the pattern is reached.

## Matching (`rx/nfa.py`)

- `compile(pattern)` takes a pattern string or an AST node and returns an `NFA`. A string that does not parse raises `RegexError`.
- `NFA.match(text) -> bool` is true when the whole text matches.
- `NFA.search(text, start=0)` returns `(i, j)` for the leftmost match that begins at or after `start`, and among the matches beginning at `i` the longest one; it returns `None` if there is no match. An empty match counts, so `search` of `a*` in `"bbb"` is `(0, 0)`.
- `NFA.findall(text)` returns the list of matched substrings, scanning from position 0: take `search(text, pos)`; stop if there is none; append `text[i:j]`; continue from `j`, or from `j + 1` if the match was empty. So `findall` of `a*` in `"baa"` is `['', 'aa', '']`.
- The module-level `match(pattern, text)`, `search(pattern, text, start=0)` and `findall(pattern, text)` compile the pattern and call the method.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
