Extend `lru.py` with expiry and statistics. Everything from the previous version keeps working exactly as before when no time-to-live is given.

- The constructor becomes `LRUCache(capacity: int, ttl=None, clock=time.monotonic)`. `ttl` is a number of seconds greater than 0 (`ValueError` otherwise), or `None` for entries that never expire. `clock` is a function with no arguments that returns the current time in seconds; the cache reads the time only by calling it.
- An entry expires `ttl` seconds after it was last stored by `put`: it is expired once `clock() - time_stored >= ttl`. Reading it with `get` does not extend its life.
- An expired entry behaves exactly as if it had been removed: `get` returns the default, `key in cache` is false, it does not count in `len(cache)`, it is not in `keys()`, and a `put` of its key counts as adding a new key.
- When `put` adds a new key, expired entries never count towards the capacity: the least recently used unexpired key is evicted only if the unexpired entries alone fill the cache. `put` returns only a key evicted that way, never an expired one. `resize` follows the same rule.
- `stats()` returns a dict with exactly four integer counts:
  - `hits`: calls to `get` that found an unexpired entry;
  - `misses`: calls to `get` that did not;
  - `evictions`: keys removed by `put` or `resize` to make room;
  - `expirations`: entries that have expired so far. Each expired entry counts once, whether or not anything has looked at it since; an entry that was replaced by a `put` or evicted before its time never expires.

Use only the Python 3.12 standard library. Give the complete updated files, each in its own fenced code block, with the file's path on the line just before the block.
