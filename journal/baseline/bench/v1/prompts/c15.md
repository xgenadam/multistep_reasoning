Write a Python module `linediff.py` with a function `diff(a: list[str], b: list[str]) -> list[str]` that computes a minimal line diff.

- `a` and `b` are lists of lines (strings without line endings). Lines are compared for exact equality.
- The result is an edit script: a list of entries, each a line prefixed with one character: `' '` for a line common to both, `'-'` for a line only in `a`, `'+'` for a line only in `b`. Taking the `' '` and `'-'` entries in order (without their prefix) gives back `a`; taking the `' '` and `'+'` entries gives back `b`.
- The script is minimal: its common lines form a longest common subsequence of `a` and `b`, so it has as few `-` and `+` entries as possible.
- Many scripts can be minimal, so the result is fixed by this rule. Walk both lists from the start, with `i` and `j` the positions reached in `a` and `b`:
  - if `a[i] == b[j]`, emit `' ' + a[i]` and advance both;
  - otherwise, if `LCS(a[i+1:], b[j:]) >= LCS(a[i:], b[j+1:])` (where LCS is the length of a longest common subsequence), emit `'-' + a[i]` and advance `i`;
  - otherwise emit `'+' + b[j]` and advance `j`;
  - once one list is used up, emit the rest of the other (`-` for `a`, `+` for `b`).

  One consequence: in a block of changed lines, the deletions come before the insertions.
- Example: `diff(['a', 'b', 'c'], ['a', 'x', 'c', 'd'])` is `[' a', '-b', '+x', ' c', '+d']`.
- The inputs are not modified. Inputs of a few thousand lines each must finish in a few seconds.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
