Write a Python module `search.py` with these binary-search functions. Each must run in O(log n) comparisons (O(log n) iterations for `isqrt`); do not use the `bisect` module or `math.isqrt`.

- `first_index(a, x) -> int`: `a` is a list sorted in non-decreasing order. Returns the index of the first element equal to `x`, or `-1` if there is none.
- `last_index(a, x) -> int`: the same for the last element equal to `x`.
- `insertion_point(a, x) -> int`: the smallest index `i` such that inserting `x` before `a[i]` keeps `a` sorted (so `x` goes before any equal elements); `len(a)` if `x` is greater than every element.
- `count(a, x) -> int`: how many elements equal `x`.
- `search_rotated(a, x) -> int`: `a` is a list of distinct values that was sorted in increasing order and then rotated by some amount (possibly zero), such as `[40, 50, 10, 20, 30]`. Returns the index of `x`, or `-1`.
- `rotation_offset(a) -> int`: for such a rotated list, the index of its smallest element (0 for a list that is not rotated). `ValueError` if `a` is empty.
- `isqrt(n: int) -> int`: the largest integer `r` with `r * r <= n`, exact for arbitrarily large integers. `ValueError` if `n` is negative; `TypeError` if `n` is not an `int` (a `bool` counts as not an `int`).

All functions accept empty lists (except `rotation_offset`) and must not modify their arguments.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
