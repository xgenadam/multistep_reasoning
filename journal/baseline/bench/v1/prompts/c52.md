Write an in-memory filesystem with a tiny shell in Python, as a package `vfs`. It is for teaching: students run small scripts of shell-like commands against it and compare the output.

Layout:

```
vfs/__init__.py   re-exports FileSystem, Shell, the error classes, normalize, join, split
vfs/paths.py      normalize, join, split, is_within
vfs/fs.py         FileSystem and the errors
vfs/shell.py      Shell; running `python -m vfs.shell SCRIPT` runs a script file
```

## Paths (`vfs/paths.py`)

Paths use `/`. A name is any non-empty string without `/`; `.` and `..` are special.

- `normalize(path, cwd='/')` returns an absolute path with no `.` or `..` parts, no repeated `/` and no trailing `/` (except the root, `/`). A relative path is taken relative to `cwd` (an absolute normalised path). `..` goes up one level, and `..` at the root stays at the root. An empty `path` raises `ValueError`.
- `join(base, *parts)` joins like `posixpath.join` (a part starting with `/` starts over) and returns the result normalised.
- `split(path)` takes an absolute normalised path and returns `(parent, name)`; `split('/')` is `('/', '')`.
- `is_within(path, ancestor)` tells whether the normalised `path` is `ancestor` itself or lies below it (`/ab` is not within `/a`).

## Filesystem (`vfs/fs.py`)

`FileSystem()` starts with an empty root directory, and its current directory is `/`. Every method takes paths that may be relative to the current directory. Files hold text.

Errors: `FSError` (a subclass of `Exception`) and its subclasses `NotFound`, `AlreadyExists`, `NotADirectory`, `IsADirectory` and `InvalidOperation`. For every error, `str(error)` is exactly one normalised absolute path, chosen as in the rules below. When an operation's path passes through an existing file (as in `/notes.txt/x`), the error is `NotADirectory` with that operation's path.

| Method | Behaviour | Errors, checked in this order |
| --- | --- | --- |
| `pwd()` | the current directory | |
| `cd(path)` | change directory | `NotFound(path)`; `NotADirectory(path)` if it is a file |
| `mkdir(path, parents=False)` | create a directory; with `parents`, also create missing parents, and an existing directory is not an error | `AlreadyExists(path)` if it exists (with `parents`, only if it is a file); `NotFound(path)` if the parent is missing and not `parents` |
| `write(path, text, append=False)` | create or overwrite the file, or add to its end with `append` | `IsADirectory(path)`; `NotFound(path)` if the parent is missing |
| `read(path)` | the file's text | `NotFound(path)`; `IsADirectory(path)` |
| `ls(path='.')` | for a directory, its entries' names sorted as strings, each directory's name followed by `/`; for a file, a one-item list of its name | `NotFound(path)` |
| `rm(path, recursive=False)` | remove a file, or a directory and everything in it with `recursive` | `NotFound(path)`; `InvalidOperation(path)` if it is `/`, the current directory or one of its ancestors; `IsADirectory(path)` if it is a directory and not `recursive` |
| `mv(src, dst)` | move or rename a file or directory; if `dst` is an existing directory, the target is `dst/NAME` (NAME being `src`'s name), otherwise the target is `dst` | `NotFound(src)`; `InvalidOperation(src)` if `src` is `/`, the current directory or one of its ancestors; `InvalidOperation(src)` if the target is `src` itself or inside it; `AlreadyExists(target)` if the target exists; `NotFound(dst)` if the target's parent is missing |
| `find(path='.', pattern='*')` | the absolute paths of everything below `path` (not `path` itself) whose name matches the glob `pattern` (`fnmatch.fnmatchcase`), sorted as strings; for a file, `[its path]` if its name matches, else `[]` | `NotFound(path)` |
| `exists(path)`, `is_dir(path)` | booleans, never raise | |

## Shell (`vfs/shell.py`)

`Shell(fs=None)` wraps a `FileSystem` (a new one if `None`), available as `shell.fs`; state carries over between runs. `run(script)` runs a script and returns `(output, status)`.

- The script is split into lines, numbered from 1. Each line is stripped; empty lines and lines starting with `#` are skipped. A line is split into words with `shlex.split`, so quotes work.
- Commands, where `[-p]` and `[-r]` are only recognised as the first argument:

  | Command | Output |
  | --- | --- |
  | `pwd` | the current directory and `\n` |
  | `cd PATH` | |
  | `mkdir [-p] PATH...` | |
  | `ls [PATH]` | each entry and `\n` |
  | `rm [-r] PATH...` | |
  | `mv SRC DST` | |
  | `write PATH [WORD...]` | (writes the words joined by single spaces, plus `\n`) |
  | `append PATH [WORD...]` | (the same, appended) |
  | `cat PATH...` | each file's text, as it is |
  | `find [PATH] [-name PATTERN]` | each path and `\n` |

  Commands with several paths handle them left to right.
- The output is everything the commands printed, concatenated. The first error stops the script: an `FSError` adds the line `line N: COMMAND: ErrorClassName: PATH` and `\n` and the status is 1; an unknown command adds `line N: COMMAND: unknown command` and `\n`, and wrong arguments (a missing or extra argument, an argument starting with `-` other than the recognised flags, or a quoting error) add `line N: COMMAND: usage` and `\n`, both with status 2. Otherwise the status is 0. Here `COMMAND` is the line's first word.
- `python -m vfs.shell SCRIPT` runs the file `SCRIPT` in a new shell, writes the output to stdout and exits with the status. If the file cannot be read it prints a message starting with `error:` to stderr and exits with 2.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
