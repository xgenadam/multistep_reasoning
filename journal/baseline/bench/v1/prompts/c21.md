Write a Python module `matrix.py` for exact linear algebra on small matrices represented as lists of rows, using `fractions.Fraction`.

- A matrix is a non-empty `list` of non-empty `list` rows, all of the same length. Every element must be an `int` or a `Fraction`; any other element type (including `float` and `bool`) raises `TypeError`. A value that is not a list of lists, an empty matrix, an empty row or ragged rows raises `ShapeError`.
- Exceptions: `class MatrixError(Exception)`, `class ShapeError(MatrixError)` and `class SingularMatrix(MatrixError)`.
- `det(m) -> Fraction`: the determinant of a square matrix (`ShapeError` if not square).
- `inverse(m) -> list[list[Fraction]]`: the inverse of a square matrix; `ShapeError` if not square, `SingularMatrix` if the determinant is 0.
- `solve(a, b) -> list[Fraction]`: the vector `x` with `a·x = b`, where `a` is a square `n×n` matrix and `b` is a list of `n` numbers (a flat list, with the same element rule). `ShapeError` if `a` is not square or `b` does not have length `n`; `SingularMatrix` if `a` is singular.
- `matmul(a, b) -> list[list[Fraction]]`: the product; `ShapeError` if the number of columns of `a` differs from the number of rows of `b`.
- `identity(n) -> list[list[Fraction]]`: the `n×n` identity; `ValueError` if `n < 1`.
- Every result element is a `Fraction` (also for integer input), and results are always new lists: the functions never modify their arguments.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
