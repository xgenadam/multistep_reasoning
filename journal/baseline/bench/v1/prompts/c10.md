Write a Python module `rle.py` with run-length encoding for arbitrary strings, digits and backslashes included.

The encoded format:
- The input is split into maximal runs of one repeated character.
- A character is written as itself, except that a decimal digit `0`–`9` or a backslash `\` is written with a backslash before it (`\7`, `\\`). Every other character, including spaces, newlines and non-ASCII characters, is written as itself.
- A run of length 1 is just the written character. A run of length n ≥ 2 is n in decimal followed by the written character.

Examples, with the text shown as it is rather than as Python string literals: `aaab` encodes as `3ab`; `a1` as `a\1`; `111` as `3\1`; a single backslash `\` as `\\`; twelve `x` followed by `22` as `12x2\2`; and the empty string as the empty string.

Functions:
- `encode(text: str) -> str` returns the encoding described above, always with maximal runs.
- `decode(data: str) -> str` reverses it. It accepts any well-formed input, including input that `encode` would not produce because runs are split (`2a2a` decodes to `aaaa`, and `aa` to `aa`). Well-formed means a sequence of items, each an optional count followed by one written character, where:
  - a count is a decimal number of 2 or more with no leading zero;
  - a written character is either a character that is not a digit and not a backslash, or a backslash followed by a digit or a backslash.

  `decode` raises `ValueError` for anything else, for example (again shown as is): a count of 0 or 1 or with a leading zero (`1a`, `0a`, `02a`), a count with nothing after it (`3`, `a12`), a backslash followed by any other character (`\a`), or a lone backslash at the end (`ab\`).
- Both functions raise `TypeError` if their argument is not a `str`.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
