Write a Python module `lru.py` with a class `LRUCache`, a fixed-capacity cache that evicts the least recently used entry.

- `LRUCache(capacity: int)` raises `ValueError` if `capacity` is less than 1.
- `get(key, default=None)` returns the value stored for `key` and makes `key` the most recently used. If `key` is missing it returns `default` and changes nothing.
- `put(key, value)` stores `value` under `key` and makes `key` the most recently used. If `key` is new and the cache is already full, it first evicts the least recently used key and returns that key; otherwise it returns `None`. Updating an existing key never evicts anything.
- `len(cache)` is the number of entries, and `key in cache` tells whether `key` is stored without changing which key is most recently used.
- `keys()` returns a list of the stored keys from least to most recently used.
- `resize(capacity: int)` changes the capacity (`ValueError` if less than 1), evicts least recently used keys until the cache fits, and returns the list of evicted keys in the order they were evicted.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
