Our internal tool `logslice` has only its `--help` output as documentation, and people keep asking the same questions in chat. Write a user guide page for the internal wiki, for engineers who are comfortable on the command line but have never used the tool.

Here is the complete `--help` output:

```
usage: logslice [-h] [--version] [--since TIME] [--until TIME] [-l LEVEL]
                [-g PATTERN] [-x PATTERN] [--format {auto,json,logfmt,plain}]
                [--fields LIST] [-n N] [--tz ZONE] [--count] [--no-color]
                FILE [FILE ...]

Print the lines of one or more log files that fall in a time window and
match the given filters, in time order. Files ending in .gz are read
transparently. Use - as FILE to read standard input.

positional arguments:
  FILE                  log file(s) to read; - for standard input

options:
  -h, --help            show this help message and exit
  --version             print the version and exit
  --since TIME          only lines at or after TIME: an ISO 8601 timestamp
                        (2024-05-01T09:30) or a relative time (15m, 2h, 3d)
  --until TIME          only lines before TIME (same forms as --since)
  -l, --level LEVEL     minimum level: debug, info, warn or error
                        (default: debug, i.e. all lines)
  -g, --grep PATTERN    only lines matching the regular expression PATTERN;
                        may be repeated, and a line must match all of them
  -x, --exclude PATTERN drop lines matching PATTERN; may be repeated
  --format {auto,json,logfmt,plain}
                        how to parse lines (default: auto, detected from the
                        first 50 lines); plain does no parsing, so --level
                        and --fields do not apply
  --fields LIST         json and logfmt only: comma-separated fields to print,
                        in that order, instead of the whole line
  -n, --max-lines N     stop after N matching lines
  --tz ZONE             time zone for timestamps without an offset, and for
                        --since/--until (default: UTC)
  --count               print only the number of matching lines
  --no-color            do not colour the level names in the output

exit status:
  0  at least one line matched
  1  no lines matched
  2  usage error: unknown option or unparseable TIME
  3  a FILE does not exist or cannot be read
  4  more than 10% of lines could not be parsed in the chosen format
     (try --format plain)
```

It is installed with `pipx install logslice` (it needs Python 3.10 or later), or by downloading the single-file `logslice.pyz` from the internal releases page and running it with `python3 logslice.pyz`.

The page needs these sections:
- **Installation**: both ways of installing, and how to check it worked.
- **Examples**: exactly five worked examples of realistic tasks, each under its own level-3 heading (`### …`), with the command in a code block and a sentence or two on what it does and why the flags are there. Between them, cover time windows, level filtering, combining patterns, and structured logs.
- **Troubleshooting**: a table with one row for each non-zero exit status, giving the exit status, what it means and what to do about it.

Use only the options in the help text above. Do not invent flags, and don't describe behaviour the help text doesn't support. Aim for about 600-800 words.
