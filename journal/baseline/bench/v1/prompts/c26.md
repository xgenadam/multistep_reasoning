Write a command-line script `wordfreq.py` that counts word frequencies in a text file.

Usage: `python wordfreq.py PATH [--top N] [--stopwords FILE]`

- `PATH` is read as UTF-8. A *word* is a match of the regular expression `[^\W_]+(?:'[^\W_]+)*`: a run of letters or digits, which may contain single apostrophes between them (`don't`, `o'clock`). Every word is case-folded with `str.casefold()` before counting, so `The`, `THE` and `the` are the same word.
- `--stopwords FILE` names a UTF-8 file with one stopword per line. Each line is stripped and case-folded; empty lines and lines starting with `#` are ignored. Stopwords are left out of the counts.
- Output on stdout is one line per distinct word, `COUNT<TAB>WORD` (`COUNT` as a plain integer, the case-folded word), sorted by count from highest to lowest, and words with the same count in ascending order of the case-folded string (plain Python string comparison).
- `--top N` prints only the first `N` lines. `N` must be a positive integer; anything else is a usage error.
- Exit codes: 0 on success (a file without words prints nothing and exits 0); 1 if `PATH` or the stopwords file cannot be read, with the message `wordfreq: cannot read <path>` on stderr (where `<path>` is the path as given) and nothing on stdout; 2 for usage errors, as `argparse` reports them.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
