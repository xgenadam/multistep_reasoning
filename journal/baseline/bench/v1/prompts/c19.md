Write a Python module `cron.py` with a function `next_run(expr: str, after: datetime.datetime) -> datetime.datetime` that returns the next time a standard five-field cron expression fires.

- `expr` has five fields separated by runs of whitespace (leading and trailing whitespace is ignored): minute (0–59), hour (0–23), day of month (1–31), month (1–12) and day of week (0–7, where both 0 and 7 mean Sunday, 1 is Monday and 6 is Saturday). Month and day names are not supported.
- Each field is a comma-separated list of items. An item is one of:
  - `*`: every value in the field's range;
  - `N`: a single value;
  - `A-B`: the values from `A` to `B` inclusive (`A` must not be greater than `B`);
  - `*/S` or `A-B/S`: every `S`-th value of `*` or of `A-B`, starting at the range's first value (so `*/10` in the day-of-month field means 1, 11, 21, 31, and `*/15` in the minute field means 0, 15, 30, 45).
- Day of month and day of week combine as in Vixie cron: a field counts as *restricted* unless its text begins with `*`. If both fields are restricted, a day matches when it matches either field. Otherwise a day must match both (which, when one of them is `*`, means it only has to match the other).
- `after` is a naive datetime. The result is the earliest time strictly later than `after` whose minute, hour, day and month all match, with seconds and microseconds set to 0. For example, `next_run('*/15 * * * *', datetime(2026, 5, 1, 10, 15, 0))` is `datetime(2026, 5, 1, 10, 30)`, and `after` at `10:14:59` gives `10:15`.
- `ValueError` is raised for a wrong number of fields, an empty item, a value outside its field's range, a range with `A > B`, a step that is not a positive integer, `N/S`, or any other text. It is also raised when no day can ever match: the day-of-week field is not restricted and none of the listed days of month exists in any of the listed months (February counts as having 29 days), as in `0 0 30 2 *`.

Use only the Python 3.12 standard library. Give each file in its own fenced code block, with the file's path on the line just before the block.
