## What went wrong

- **The first retry design was wrong twice.** "Retry once" resent the same prompt, and the judge reproduced its malformed JSON byte for byte. The seed + 1 fix then assumed the seed matters at temperature 0. It does not, because vLLM decodes greedily, so one batch was wasted. Thinking first about what greedy decoding implies would have gone straight to the repair turn.
- **A test expectation was miscounted.** One Q-5 synthetic case expected 8/10 where the code correctly gave 9/10.

- Q-5 counts a pair-order whose two repeats both lack a verdict as a disagreement (conservative). With the repair turn in place it has not occurred.
