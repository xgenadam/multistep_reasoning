## Scope

Phase 0 item 1 / defect D1: `Part.title` and `AddPart.title` are currently
mandatory `str`, which forces the composer to invent titles for parts where
the title carries no information (and the oracle's fallback
`parts[:8]` path produces untitled-ish output downstream). Make `Part.title`
and `AddPart.title` `str | None = None`.

- `Document.render()` already handles empty titles (no heading; `## file`
  for untitled file parts — models.py:96-102).
- Add one `part.title or ''` guard in the oracle's search haystack
  (document_oracle.py).
- Update the composer prompt wherever it claims titles are required.
- Keep `to_dict()` round-trip working (None title serializes as null;
  reconstruction via `Document(**snapshot)` must not break).

## Notes

- Pass-criterion link: P0-2 (report stays sectioned) is the behavioral gate;
  the optional-title change itself is exercised through the composer's
  freedom to omit.
