## Notes

- 2026-10-19 (S-005, Opus 5.5): **Python is pinned to 3.12, not 3.13 as
  planned.** `instructor==1.3.*` requires `jiter<0.5`; jiter 0.4.2 has no
  cp313 wheel and its source build fails (`PyO3 0.21 … maximum supported
  version (3.12)`). Keeping the known-good instructor (scope rule) forces
  `requires-python = ">=3.12,<3.13"`; `make venv` asks uv for 3.12 (uv
  supplies a managed CPython 3.12.15; the box's `/usr/bin/python3` is 3.13.5).
  Lift with the instructor-upgrade ticket. `uv venv --python python3` had
  silently picked the managed 3.12 anyway, so the version is now explicit.
- `instructor==1.3.*` resolved to **1.3.7** (the old venv had 1.3.2); the
  suite and the seam test are green on 1.3.7.
- D-P precedence: `LLM_BASE_URL` → `config['key_word_args']` → explicit
  `base_url` → explicit `host`+`port` → `ValueError`. `LLMConfig` fields are
  now all optional (`base_url`, `host`, `port`); `resolved_base_url()` feeds
  `from_orchestrator_config`. Both YAMLs keep 127.0.0.1:8000 (host-side
  Devstral) and resolve exactly as before. Because the env wins inside
  `create_llama_client`, the harness refuses an explicit `--base-url` that
  differs from `LLM_BASE_URL` (exit 2) rather than silently ignoring the flag.
- Harness: `--base-url` (default `$LLM_BASE_URL`, required),
  `--judge-base-url` (default `$JUDGE_BASE_URL`; recorded as
  `judge_backend`, unused until Q-01); run-file `backend` is now
  `str(client.base_url)` of the client actually used.
- Seam test (`tests/test_llama_utils/test_instructor_seam.py`) loads the
  real `journal/baseline/harness.py` and uses its `install_instrumentation`
  over an `httpx.MockTransport` client: the per-request path is counted with
  usage tokens; an instructor client built before instrumentation reaches the
  server but is counted 0 times. Gotchas: the harness module must be in
  `sys.modules` before exec (its dataclasses resolve annotations there);
  instructor returns a subclass of the response model, so compare fields,
  not models.
- `.gitignore` gained `.venv/`, `*.egg-info/`, `.pytest_cache/` (otherwise
  `make venv` leaves untracked junk); O-02 still rewrites the whole file.
- Interpreter rule for AGENTS.md (O-01 writes it in full): `.venv/bin/python`
  if present, else `dsh-podman-venv/bin/python`; prefer `make test`.
- Probe: `LLM_BASE_URL=http://host.containers.internal:5000/v1` →
  `client.models.list()` answered with an empty list (server up, no model
  loaded), as in S-004.
