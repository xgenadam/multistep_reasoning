## Scope

Source: `journal/plan-2026-10-18-approved.md` § 2.2 "O-03", decision D-P, defect N6.
Zero behaviour change for a correctly configured caller; the only functional
change is that a *missing* endpoint now fails loudly instead of silently
using 127.0.0.1:5000 (which this container refuses — the server is only at
`http://host.containers.internal:5000`).

1. **`pyproject.toml`** at the repo root: `requires-python >= 3.12`;
   dependencies `openai>=1.109,<2`, `instructor==1.3.*` (the installed,
   known-good version for the instrumentation seam; upgrading instructor is a
   separate later ticket), `pydantic>=2`, `pyyaml`; extras `test` (`pytest`),
   `tokens` (`tiktoken`). Package discovery: `reasoning_sub_agents` only
   (`oobabooga_extension/` is copied into the webui, not installed).
2. **`requirements.txt`** becomes the curated runtime list (it is the file
   README tells oobabooga users to install); delete `requirements.txt.bak`.
3. **`Makefile`**: `venv` (`uv venv .venv && uv pip install -e '.[test]'`;
   `uv` is at `/usr/local/bin/uv`, PyPI is reachable; fall back to
   `python3 -m venv .venv && .venv/bin/pip install -e '.[test]'`), `test`
   (`pytest tests/ -q`), `smoke` (`journal/baseline/harness.py --smoke`),
   `check`, `board` (placeholder until O-01 adds `journal/board.py`).
   Interpreter rule for AGENTS.md (O-01 writes it; note it here): use
   `.venv/bin/python` if present, else `dsh-podman-venv/bin/python`
   (the latter has no interpreter in this container).
4. **D-P, no silent endpoint default**: `LLMConfig` (`config/schema.py:6-8`)
   gains `base_url: str | None`; resolution order env `LLM_BASE_URL` → YAML
   `llm:` → explicit args; `create_llama_client` (`llama_utils.py:76-110`)
   raises a clear `ValueError` when nothing is configured (no 127.0.0.1:5000
   fallback); `journal/baseline/harness.py` gains `--base-url` (default from
   `LLM_BASE_URL`) and writes the run-file `backend` field from the client's
   real `base_url` (today `harness.py:52-53,403,448` print a label that is
   not the endpoint used at `:406`). Port 8000 in the YAMLs/`config.json`/
   `start_llama.sh` is the host-side Devstral configuration — leave it.
   Add a `judge.base_url` placeholder in the harness config for Phase Q.
   Update `README.md`/`orchestrator.yaml` comments minimally so the rule is
   visible (O-05 does the full README).
5. **Instructor-seam test** (`tests/test_llama_utils/`): the harness's
   `install_instrumentation` replaces `client.chat.completions`; it is only
   seen because `instructor.from_openai` is invoked per request
   (`llama_utils.py:260`). The test builds a real `openai.OpenAI` client over
   an `httpx.MockTransport`, installs a counting wrapper on
   `chat.completions`, calls `get_streamed_json_response`, and asserts the
   wrapper saw the call; a second assertion shows that an instructor client
   constructed once up-front would bypass the wrapper (documents why the
   per-request construction must stay).
6. Run `make venv && make test`. Expected 186 passed / ≤ 10 skipped /
   0 failed. **Record the exact result** in § Measurements; any difference

   accepted, not silently skipped. If PyPI is unreachable at execution time,
   record `deferred (no network/interpreter)`.
7. One commit (explicit paths): `pyproject.toml`, `Makefile`,
