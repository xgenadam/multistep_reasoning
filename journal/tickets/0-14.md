## Scope

Source: PLAN.md § Phase 0 close-out, defects N13–N17, D-007. The harness and
`compare.py` must tell the truth before anything is re-measured (0-16, 0-06,
0-09). All of this is provable offline with a fake client, so no server is
needed.

Files: `journal/baseline/harness.py`, `journal/baseline/check.py`,
`journal/baseline/compare.py`, tests.

1. **N13, labels.**
   - `classify_call` (`harness.py` ≈ :74) guesses from system-prompt
     keywords. Executor rounds land in `summary`; real summary updates and
     the critique land in `system_other`.
   - Label each call from the orchestrator's phase instead. `_current_phase`
     (≈ :69) is already set from every status event (≈ :347); map those
     statuses to kinds (`decompose`, `decompose_critique`, `executor_turn`,
     `oracle`, `compose`, `consolidate`, `summary`).
   - Keep the keyword classifier only as a fallback, and record which path
     labelled each call.
   - Labels must sum to the call total, with no `system_other`/`unknown`
     left in a fresh run.
2. **N14, exact attribution.**
   - Per-turn stats currently slice a global call counter, so at
     `--jobs > 1` they include calls from concurrent turns (≈ :335-363).
   - Add a turn-id ContextVar per scenario thread and attribute each call to
     its turn.
   - The thread pool must propagate context (`contextvars.copy_context()`
     per job).
3. **N15, streamed usage.**
   - Pass `stream_options={'include_usage': True}` on streamed calls and read
     the final usage chunk.
   - If llama.cpp omits usage, record `usage: null` and count the streamed
     calls separately, so totals say they are partial.
4. **N16, executor status.** Make `exec_status_counts` record the real
   `TaskStatus` per sub-task, including budget-exhausted / partial, instead
   of `{'None': n}`.
5. **N17, check.py.**
   - Add the P0-1 "no prose-report parts" check, the P0-2 "no file parts"
     check, and the P0-3 "op log has merge_parts or a patch" check.
   - The Jaccard dedupe check must report `n/a`, not 0, on single-part
     documents.
6. **`llm_stats`:** per-kind `prompt_tokens`/`completion_tokens` sums.
7. **compare.py (D-007):**
   - G2 := marginal tokens (the `consolidate` call plus the summary call it
     triggers) ÷ the turn total, gated at ≤ 25%. G1 is unchanged.
   - **Exit 2 "contaminated"** when either run has `jobs > 1`, or its compose
     p50 is > 1.3× the recorded clean baseline. Use S-002's 18 s until 0-16
     replaces it, and keep the value in one constant.
   - The run file's `base_url` is printed.
8. **Verify:**
   - Re-score the nine tracked run files. S-002's compose, consolidate and
     decompose verdicts must reproduce; old files lack phase labels, so
     score them with the fallback.
   - A fake-client test at `jobs=3` proves the per-turn sums equal the
     global totals and that no call is attributed to the wrong turn.
   - `make test` is green.

When P0-6 passes, rewrite AGENTS.md's "approximate until 0-14" caveat and
