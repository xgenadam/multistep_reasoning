## Scope

Source: PLAN.md § Phase A, D-001. This is the largest A ticket: `tools.py`
is ≈ 125 lines, `document_oracle.py` ≈ 185 and `oracle_loop_executor.py`
≈ 278, plus tests. Start in plan mode.

- Replace the tool set that is closed in three places with a `ToolRegistry`
  (name → schema + handler). The three places are the `oracle/tools.py`
  union, `DocumentOracle._run` dispatch, and the concrete type hints.
- Loop mechanics stay unchanged: round budget, last-turn forcing,
  empty-result retry, budget-exhausted fallback.
- The oracle takes a set of `ContextStore`s, and tools take a `store`
  param. With only `Document` present this is plumbing, but it is the door
  in its final shape.
- A-7: a test registers a dummy tool in one place and the executor calls
  it.
- Phase P later only *registers* code tools here.
