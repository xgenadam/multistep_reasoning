## Scope

Phase 0 item 3 / defect D2: `COMPOSE_PROMPT` (document_composer.py:32)
doesn't surface `move_part`, `delete_part`, or (once 0-03 lands)
`merge_parts`, and doesn't document that titles are optional. Changes:

1. List the full op set in the prompt with a one-line semantic each.
2. Document that `title` is optional (lands with 0-02).
3. Add the **dedupe rule** — the highest-leverage change for the known
   repetition problem: *if a new part overlaps an existing one, prefer
   `merge_parts` or a targeted patch over a near-duplicate `add_part`.*

Baseline evidence for why: S-002 smoke run shows the composer emits 3
`add_part` ops with zero use of any other op, and max pair Jaccard 0.35 on
a single-prompt run — repeated-structure prompts (s3) will be worse.

## Notes
