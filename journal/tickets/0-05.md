## Scope

Phase 0 item 4 / defect D5: the composer always emits prose `section`
parts, so "write a CLI tool that does X" returns a report *about* the tool
instead of runnable code. Changes:

1. Teach the composer to emit `file` parts for code artifacts — rendering
   already code-fences with a language inferred from the filename
   (models.py:132), so this is prompt work plus the filename convention
   (the `file` part's title should carry a filename with extension).
2. Add an output-shape hint to the **decomposer** so code requests yield
   code sub-tasks (e.g. "write the wordcount.py script") rather than
   "design", "explain", "summarize" sub-tasks — the S-002 smoke run
   decomposed a CLI request into 3 prose sub-tasks
   ("Design CLI argument parsing…", "Implement counting logic…",
   "Write the final complete wordcount.py script") and composed 3 sections.
