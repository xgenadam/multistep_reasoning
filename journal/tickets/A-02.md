## Scope

Source: PLAN.md § Phase A, D-001, defect register N5.

- Implement A-01's `ContextStore` for `Document` in a new `context/` package
  beside the existing layout (no rename, D-001).
- **BM25:** hand-rolled, ≈ 60 lines, stdlib only (A-5). It replaces
  `DocumentOracle`'s literal substring search.
- **Delete the first-8-parts fallback** in `ask`
  (`document_oracle.py`, `self.document.parts[:8]`). `ask` returns the
  ranked top-k with per-part citations.
- **N5:** the search excerpt's index is computed on `title + '\n' + body`
  but sliced on `body` (≈ :91-95, 177-185). It dies in the rewrite; add a
  long-title regression test.
- **The needle set:** 10 identifiers or strings planted in specific parts of
  a > 30-part fixture document, with 5 of them in the last third. A-2 and A-3
  are measured offline on it; no LLM is involved in `search`.
  - A-2: the containing part is in the top 3 for ≥ 8/10.
  - A-3: BM25 recalls a strict superset of what substring search did.
  - The fixture is reused by A-05.
