## Scope

Two defects found by the baseline harness (S-002):

1. **No `Document.from_dict()`** — `to_dict()` (models.py:122) exists for
   snapshots, but reconstruction is hand-rolled. The baseline harness had to
   rehydrate parts/op_log manually with `Part.model_validate` /
   `AppliedOp.model_validate`, and a raw `Document(**snapshot)` crashes with
   `AttributeError: 'dict' object has no attribute 'id'` in
   `outline()` (models.py:81) — that killed both s3_followup baseline runs
   (multi-turn continuation is exactly what Phase P's frozen snapshots will
   need). Add `Document.from_dict(cls, d)` as the canonical inverse of
   `to_dict()` and use it in the harness.

2. **8 pre-existing test failures** (see 0-07 measurements for the list):
   5× stale `get_streamed_boolean_decision` mocks, 2× missing `import
   pytest`, 1× composer prompt-contract assertion
   (`KEEP-SECRET-BODY` leaking into the prompt). Fix the mocks/imports; for
   the prompt-leak one, decide: is part body in the compose prompt
   intentional (it must be, for targeted patches) → update the test to the
   actual contract.
