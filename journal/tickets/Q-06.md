## Scope

Source: Q-01 Notes 2026-10-19 ("hand labels on hold"); the PLAN task-board
row it replaces; the user's choices of 2026-10-23 (assistant in v1, built in
the agent's session). Gates Q-1's real-pair half (Q-01) and Q-04's
label-agreement column, and through D-021 the judge of record.

- **App** (`labelling_app/`): a local web page served by `server.py`
  (standard library plus PyYAML, so it runs on the host or in the
  container). The task and both candidates are shown side by side. Choose
  Left, Tie or Right, add an optional note, then save and go to the next
  pair. Keys 1/2/3 pick, Ctrl+Enter saves.
- **Blinding:** the display order is shuffled per pair by a stable hash
  and recorded with the label. The page never receives a pair's source,
  run ids or kind. The server never reads judge verdict files.
- **Assistant:** any OpenAI-compatible endpoint, named explicitly
  (`--assist-base-url`, `--assist-model`; D-008, off when unset). It is told
  to answer factual questions about the task and the two responses and
  never to say or hint which is better. Its questions and answers are saved
  with the label. **Default model: Qwen3.8-27B**, which is not a judge
  candidate, so the assistant cannot lean the labels toward a judge being
  scored on them (flash-next, Devstral and the other Q-04 candidates are
  all scored against these labels).
- **Labels file:** `labels.yaml` beside the manifest
  (`journal/baseline/bench/validation/labels.yaml`, tracked), recording per
  pair the canonical label, the display order, the note, the time spent,
  the assistant transcript and earlier labels as history. `quality.py`
  fills an empty `expected` from it and raises if a label contradicts a
  manifest `expected`; `quality.py report --pairs` re-scores an existing
  verdict file against the current labels without new judge calls.

**Done when (Q-11):** the app runs as above, the tests pass, and R1–R5 are
labelled through it. Then Q-01 re-scores Q-1's real half from the verdict
files of record and D-021's condition is checked.
