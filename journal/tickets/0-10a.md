## Scope

Source: PLAN.md § Phase 0 close-out, defect register N2. This is the cheap
half of N2 and is behaviour-identical by construction.

In `self_critique_decomposition.py` (≈ :158-177), `should_regenerate` is
`len(sub_tasks) < 3`. The critique text never influences the outcome, so
when the first decomposition already has ≥ 3 sub-tasks the critique call
(40–97 s) is pure cost. Skip it in that case, and leave everything else
unchanged.

- Unit test: with ≥ 3 sub-tasks the critique is not called; with < 3 it is,
  and regeneration still happens.
- Behavioural check: one s1–s4 pass (`--jobs 3` is fine).
  - Turns with ≥ 3 sub-tasks show 0 `decompose_critique` calls (0-14
    labels).
  - The sub-task-count distribution matches 0-16's baseline.
- Commit the run file with a dated Notes bullet.
