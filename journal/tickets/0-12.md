## Scope

Source: PLAN.md § Phase 0 close-out, defect register N3, N4 and N7. Each
fix ships with a test that fails on the pre-fix code (P0-8).

1. **N4.**
   - A budget-exhausted `OracleLoopExecutor` returns `TaskStatus.COMPLETED`
     with "Partial result…" text (`oracle_loop_executor.py` ≈ :211-231).
   - Add `TaskStatus.PARTIAL` and return it, so verifiers can trust
     `status`.
   - Check every `status ==` consumer.
2. **N7.**
   - `TaskOrchestrator` stores component histories by reference
     (`task_orchestrator.py` ≈ :158-167), so a long-lived orchestrator
     mutates earlier turns.
   - Store copies.
3. **N3.**
   - A compose batch made only of replace/merge/move/delete ops passes
     `assert_payload_kept` unconditionally (`document/integrity.py`
     ≈ :13-61), so a sub-task result can silently vanish.
   - Require ≥ 0.8 of the result's distinct content tokens to be present
     after apply.
   - If this fights the composer prompt (false rejections on legitimate
     edits), split N3 into its own ticket. Record why in Notes and close
     this one on N4 + N7.
