## Notes

- 2026-10-19 (S-008, from 0-14; handoff, not work on this ticket):
  - **Contamination gate.** `check.py <run>` prints `timing: clean |
    CONTAMINATED` per turn. That is the per-run form of compare.py's rule.
    Its yardstick, `compare.CLEAN_COMPOSE_P50_S = 18.0`, is S-002's 27B
    number. Replace it with this ticket's measured compose p50, and only
    run against the generator it was measured on.
    - The compose-only proxy flags s3 follow-up turns, where compose sees a
      grown document (0-14 Notes). Use a per-turn yardstick for multi-turn
      scenarios, or accept the noise and say so.
  - **P0-3 on s3.** The re-run s3 is the first fresh run scored by the
    P0-3 part-identity check (D-014). Both tracked rebuild follow-ups fail
    it: each drops turn 0's part and re-adds the text under a new id (0-14
    Notes). Watch that row.
- 2026-10-19 (S-009, from 0-15; handoff, not work on this ticket):
  - **Thinking.** `harness.py --thinking` defaults to `off`, which is the
    D-013 baseline setting, so do not pass `on`. Each run file's
    `thinking` header records the setting, and `check.py`'s Run line
    prints it. `calls_without_switch` must be 0. A run whose header says
    `unrecorded (pre-0-15)` predates the switch and is not a baseline.
  - On `:8091`, s1 with thinking `on` took 356 s against 59 s with `off`,
    and 39.9 K completion tokens against 5.7 K. Those are single points
    (0-15 Notes). Measuring `on` is a separate comparison after this
    ticket.
